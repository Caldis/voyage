# 调试面板 UI/UX 规范（PANEL_UX_GUIDE）

> 维护者：交互设计师（面板 UI/UX，按节点介入，见 `DEV_SOP.md` 角色表）。首版：2026-09-28（UX-1）。
> **凡是新增或改动面板控件的任务，简报必须引用本文件；审查按本文件第 11 节「审查清单」核对。**
> 本次审计与改动任务清单见 `research/PANEL_UX_AUDIT_1.md`。

## 0. 结论先行

1. **面板服务于「看窗外」**，本身不是产品。原则：默认少、按需展开、永远能一键收起；桌面上面板遮挡的画面不超过视口面积的 **20%**，窄屏不超过 **40%**，而且不能压住舷窗中心。
2. **按用户目的分六区**：观景、航程、天气、声音、画质、开发者。前两区默认展开，天气 / 声音 / 画质默认折叠，只显示一行摘要；「开发者」区对普通用户隐藏（`?dev` 或 `Shift + D` 打开）。
3. **系统在驱动的值必须如实显示**：连续航程（即将默认开）接管天气、时间、高度、地点、风速时，对应控件要跟着实际值走，并标出「自动」，不能停在上一次手动设的数上（现状违反，见审计 P1）。
4. **一种意图，一种控件**：2–4 个短选项用分段按钮，5 个以上或选项名较长用下拉，连续量用滑条，开关用开关；离散的 4 档不用滑条。
5. **记忆有边界**：只记「观看偏好」（座位、视角、舱等、连续航程开关、声音选项、地面精度、面板折叠），不记「场景状态」（时间、天气、画质档）。优先级统一为 **URL 参数 > 用户上次手动的选择（localStorage）> 默认值**；脚本派发的事件不写记忆。有一键「恢复默认」。
6. **控件用声明式描述**（第 10 节）：一个控件写一条描述，渲染、记忆、复位、URL 参数、接管显示、脚本句柄都由框架统一处理，新控件不再手写 index.html + ui.ts + main.ts 三处。

## 1. 适用范围与术语

- **面板**：`#panel`（`index.html` 里的 `<aside>`，逻辑在 `src/ui.ts`），以及挂在面板外的叠层提示（背景板提示 `#backdrop-hint`、火车字幕 `#rail-caption`、软件渲染提示 `#software-gl`、调试小地图）。
- **普通用户**：打开页面当背景看风景的人。不知道 EV、GPU 预算、clipmap 是什么，也不需要知道。
- **开发者**：本仓库的代理和用户本人做调试、截图、测量时。
- **接管**：某个控件对应的状态正在由系统（导演、天气导演、自动画质、火车模式）驱动，手动值暂时不生效或只短暂生效。
- **控件 id 契约**：`scripts/scenarios.mjs` 的 `applyScene`、`regression.playwright.js`、`dev-browser.mjs` 的截图 JSON（`panel` 字段）都**按 DOM id 设值并派发 `input` / `change` 事件**。任何改版都**不能改 id、不能改选项的 value**（例如 `cabin-light` 的 `true / false / off`），也不能把控件从 DOM 里删掉（藏起来可以）。改 id 必须同时改场景表并在任务里写明。

## 2. 信息架构

### 2.1 分区（从上到下）

| 区 | 用户目的 | 默认 | 放什么 | 不放什么 |
| --- | --- | --- | --- | --- |
| **标题栏**（常驻） | 知道自己在哪、随时收起 | 显示 | 应用名；交通工具分段（飞机 / 火车）；收起按钮（×，等价 `H`）；快捷键帮助按钮（`?`） | 长说明文字 |
| **此刻**（常驻摘要，1–3 行） | 一眼知道窗外是哪、什么时候 | 显示 | 航段「上海浦东 → 东京成田 · 巡航 · 10×」；当地时刻；窗外朝向；天气一句话 | 太阳 / 月亮高度角、经纬度小数点后三位（移到开发者区） |
| **观景** | 调整「我怎么看」 | 展开 | 座位（左 / 右）、视角、座位相对机翼、遮光板、舱等、舱内灯光、背景板模式按钮、奇观模式开关与稀有度 | |
| **航程** | 调整「飞到哪、多快」 | 展开 | 连续航程开关 + 流速（一行，模式决定选项）、起点 / 航线、航向（自动航线 / 保持航向 / 盘旋、左右转、选定航向）、直飞机场、日期与时刻、高度与飞行阶段 | 调试「立即到达」 |
| **天气** | 换一种天 | 折叠（摘要行显示当前天气与是否「自动」） | 天气系统、云型、云量、云底高度、云层厚度、海面风速；连续航程开着时的「手动天气」开关（见 5.3） | |
| **声音** | 开 / 关、音量 | 折叠（标题行本身带开关） | 声音开关、音量、空调出风、客舱提示音、火车钢轨接缝（火车模式才显示） | |
| **画质** | 帧率不够时降一档 | 折叠（摘要行显示「自动 · 高」） | 画质档、地面精度、真实地理数据、人眼式自动曝光、曝光补偿 | GPU 毫秒数（开发者区） |
| **开发者**（默认隐藏） | 调试、测量 | 隐藏；`?dev` 或 `Shift + D` 显示，状态记忆 | 调试小地图、立即触发到达、奇观召唤 / 退场 / 指定、手动曝光 EV、完整信息栏（日月高度角、经纬度、瓦片数）、画质自适应依据（GPU ms / 预算）、地面精度判定依据、当前生效的 URL 参数 | |
| **页脚** | 许可合规 | 折叠为一行「数据来源与许可」 | 影像 / 地形 / 星表署名（**不能删**，许可要求可见） | |

排序原则：**越常用越靠上、越影响画面越靠上、越「开发者」越靠下**。同一区内按「看得见的效果大 → 小」排。

### 2.2 分层（普通 / 进阶 / 开发者）

每个控件必须标一个层级（框架字段 `tier`）：

- `user`：普通用户会用、效果一眼可见。默认可见。
- `advanced`：普通用户偶尔用、需要一点知识（襟翼档位、曝光补偿、地面精度、云底高度 / 厚度）。放在所属区的「更多」小折叠里，或所属区本身默认折叠。
- `dev`：只为调试 / 测量存在，或会产生「不真实」的画面（立即到达、奇观召唤、手动 EV、小地图）。只在开发者区。

**判定口诀**：普通用户按下去会不会困惑或看到不该看的？会 → `dev`。文案里带「（调试）」二字的，一律归 `dev`，而不是在用户区里加个括号。

### 2.3 折叠与摘要

- 用原生 `<details><summary>` 实现分区（键盘、读屏器、无 JS 都能用）。
- 折叠区的 `summary` 行右侧给**一行摘要**（例：「天气 · 自动 · 层积云 78%」「画质 · 自动 → 中」「声音 · 关」），让人不展开也知道状态。
- 折叠状态记忆（见第 7 节）。
- 展开 / 折叠不能改变画面、不能触发任何 `apply`。

## 3. 命名与文案

### 3.1 标签

- **标签是名词短语，2–6 个汉字**：「遮光板」「舱内灯光」「海面风速」。
- **标签里不放括号说明**。说明放在控件下方的 `.hint`（一行，≤ 30 字）或 `title` 提示里。反例（现状）：「连续航程（自动接续东亚航线、时间流逝）」「调试小地图（航向 / 云回波 / 交通 / 奇观，快捷键 N；点击地图切换量程）」。
- **快捷键写成键帽**，放标签右侧：`声音 [M]`。不写「按 M 开关」这种句子。
- **按钮文案是动词短语**，≤ 6 字：「现在」「立即召唤」「退出背景板」。说明挪到 `title`。反例：「背景板模式（隐藏面板，按 Esc 或 B 退出）」。
- **选项文案**：主名在前，差异说明在全角括号里，括号内 ≤ 10 字：「商务舱」「经济舱」即可，材质描述放 `title`。
- 造的 / 未核实的内容照仓库规矩标「示例」，放在选项括号里：「火车（大糸线，示例）」。

### 3.2 数值与单位

| 量 | 格式 | 例 |
| --- | --- | --- |
| 高度、云底、云厚 | 1 位小数 + 空格 + km | `10.7 km`、`云底 1.2 km` |
| 距离 | 整数 + 空格 + km | `距终点 812 km` |
| 风速 | 整数 + 空格 + m/s | `7 m/s` |
| 角度（航向、方位） | 3 位补零 + ° + 全角括号方位 | `095°（东）` |
| 角度（高度角、坡度） | 1 位小数 / 整数 + °，不加空格 | `太阳 12.4°`、`坡度 25°` |
| 百分比 | 整数 + %，不加空格 | `云量 42%`、`遮光板 拉下 60%` |
| 曝光 | 带符号 1 位小数 + 空格 + EV | `+0.5 EV`、`−1.0 EV` |
| 倍率 | 整数 + ×，不加空格 | `60×` |
| 时刻 | 24 小时制 `HH:mm` + 全角括号时区 | `18:42（UTC+9）` |
| 纹理尺寸 | 数字 + ² | `2048²` |

- 负号用 `−`（U+2212），与现有时区显示一致。
- 范围用 `–`（en dash）：`4.5–6 km`。
- 数字与汉字之间不加空格（「云量 42%」里的空格是标签与值之间的分隔，固定一个）。
- 值的有效位数 = 滑条步长的位数，不多显示。

### 3.3 术语表（面板上只用左列，不用右列的同义词）

| 用 | 不用 | 含义 |
| --- | --- | --- |
| 连续航程 | 自动航行、巡游模式 | 导演接管：航段接力、时间流逝、天气演变 |
| 背景板模式 | 全屏模式、屏保 | 隐藏面板、连续航程播放 |
| 航段 | 航线段、leg | 一次起点 → 终点 |
| 起点 / 航线 | 地点、预设 | `#preset` 下拉（有的是航线、有的是定点） |
| 自动航线 / 保持航向 / 盘旋 / 直飞 | 路由、hold | 航向模式 |
| 流速 | 时间倍率、速率 | 时间或航程推进的倍数 |
| 天气系统 | 天气预设 | 雷暴、飑线、台风等 |
| 云型 | 云预设、云 | `#cloud-preset` |
| 画质档 | 质量、画质等级 | 自动 / 高 / 中 / 低 |
| 地面精度 | 地面分辨率、GROUND_RES | 2048² / 1024² |
| 奇观 | 彩蛋 | 奇观模式 |
| 下次载入生效 | 重启生效、刷新后生效 | 统一说法 |
| 准备中… | 编译中、加载中（面向用户时） | 后台编译 / 拉数据 |
| 自动 | 导演控制、系统控制 | 被接管时的标记 |

## 4. 控件选型

### 4.1 选型表

| 情形 | 用 | 不用 |
| --- | --- | --- |
| 两态、立即生效 | **开关**（外观为 switch 的 checkbox，`role="switch"`） | 两个按钮 |
| 2–4 个互斥选项，每个 ≤ 4 字 | **分段按钮**（`role="radiogroup"`，选中项 `aria-checked`） | 下拉（多一次点击、看不到其他选项） |
| ≥ 5 个选项，或选项名较长 | **下拉** | 分段按钮（会换行） |
| 连续量、拖动时能看到画面变化 | **滑条** + 右侧数值 | 数值输入框 |
| 离散的 ≤ 4 档 | 分段按钮 | 滑条（现状：奇观稀有度 0–3 用了滑条） |
| 需要精确数值（开发者） | 滑条 + 可编辑数值（点击数值变输入框） | 只有输入框 |
| 一次性动作 | 按钮 | 开关 |
| 按住连续变化（转向） | 按钮 + 按住重复 + 键盘等价 | 只有拖动 |

现状适用举例：座位（2）、舱等（2）、舱内灯光（3）、交通工具（2）、时间流速（4）、航程流速（3）、航向模式（3）、奇观稀有度（4）→ 分段；地点、天气系统、云型、视角、襟翼（8）、直飞机场（15）、画质档（4 但名字长 → 可分段「自动 / 高 / 中 / 低」+ 说明进 `title`）→ 按上表。

### 4.2 滑条规则

- **范围**：取物理上有意义、画面上有差别的区间，不为「好看」留空白段。不可达的部分要么收窄 `min / max`，要么在轨道上画出不可达段（现状高度滑条的下限随地形变，用动态 `min` 是对的，需在 hint 说明——已有）。
- **步长** = 显示精度（见 3.2）；肉眼分不出差别的步长不要更细。
- **默认值标记**：轨道上在默认值处画一个小刻度（`<datalist>` 或 CSS 背景渐变），拖离默认后一眼能找回。
- **复位**：**双击滑条或其标签**回到默认值（与画布双击复位视角的习惯一致）；数值 `output` 带 `title="双击复位到 X"`。
- **拖动中即时生效**（`input` 事件），昂贵的副作用（`snapAll()`、重建）放在 `change`（松手）时做，避免拖动中每帧 snap 造成云反复重置（现状云底 / 云厚每个 `input` 都 `clouds.snap()`）。
- **键盘**：方向键一步，`Shift + 方向键` 十步，`Home / End` 到两端（原生行为，不要拦截）。
- **值显示**：`output` 在标签同一行右侧、等宽数字（`font-variant-numeric: tabular-nums`），拖动时不跳宽。

### 4.3 下拉规则

- 选项多于 12 个时按组（`<optgroup>`：国内 / 日本 / 东南亚……）。
- 空选项 / 占位写成动作语：「选择机场…」，不写「（选择机场）」。
- 选完即生效的下拉，选后 `blur()`，把焦点还给画面，免得吃掉方向键（现状 `nav-dest` 已这样做，推广到所有下拉）。

## 5. 状态反馈

### 5.1 生效时机（统一三种表达）

| 生效时机 | 表达 | 例 |
| --- | --- | --- |
| 立即 | 不标 | 遮光板、座位 |
| 渐变（几秒到几分钟逐渐过去） | 控件下 hint：「逐渐过渡」，数值旁显示「当前 → 目标」 | 高度爬升 `8.2 km → 10.7 km`；导演推动云量 |
| 下次载入生效 | 控件下 hint 固定格式：**「本次：X · 下次载入：Y」**；两者相同时只写「本次：X」 | 地面精度 |

URL 参数压过面板时，在 hint 末尾加「（URL 参数 `groundres` 优先）」，并在开发者区的「生效的 URL 参数」列出。

### 5.2 准备中 / 失败

凡是后台编译、拉数据导致「选了但画面暂时没变」的：

- 控件标签右侧显示 **「准备中…」**（带转圈字符 `◐`，与加载屏风格一致），完成后消失；
- 失败显示 **「失败，保持原样」**（颜色用警示色），`title` 里写原因；
- 适用：舱等变体（已有「（准备中…）」，去掉括号统一）、切火车（已有状态文字，统一格式）、天气系统变体编译（现状无反馈，选雷暴后约 5 s 画面不变）、地面瓦片（放进「此刻」摘要：「地面影像加载中」）。
- 不弹窗、不遮画面。

### 5.3 被接管（连续航程 / 天气导演 / 自动画质 / 火车模式）

**规则一：显示实际值。** 被系统驱动的控件每 250 ms 从系统读一次实际值刷新显示（框架字段 `read`），拖动 / 聚焦期间不去抢（现状航向滑条已这样做，推广）。

**规则二：标出「自动」。** 被接管的控件标签右侧显示小标记「自动」（`title`：「由连续航程控制」）。整区都被接管时（天气），在区的摘要行写「自动」。

**规则三：手动介入的语义要写明，三选一，每个控件在描述里声明（`override` 字段）：**

| 语义 | 行为 | 适用 |
| --- | --- | --- |
| `lock`（锁定） | 接管期间控件禁用，hint 写原因与解除办法：「连续航程开着时由航程流速控制」 | 时间流速（现状已禁用，但没说明原因） |
| `nudge`（推一下） | 可以拖，拖完系统从新值接着走、慢慢拉回；标记显示「自动（已手动调整）」 | 海面风速（WX11g 现状语义）、高度（导演剖面） |
| `pause`（暂停自动） | 手动一改，该区切到「手动」，系统停止驱动这一区，直到点「恢复自动」 | 天气区（建议，见审计 P1） |

**规则四：禁用必须说明原因。** 所有 `disabled` 控件要有 `title` 或 hint 写「为什么不能用 + 怎么才能用」。现状火车模式下禁用的 9 个飞机控件没有任何说明。

**规则五：一行不同时出现两组互斥控件。** 现状「时间流速」（连续航程开着时整行禁用）与「航程流速」是两行；改为**一行「流速」**，选项随模式变（关：暂停 / 1× / 60× / 600×；开：1× / 10× / 60×）。

**规则六：显示 / 隐藏只用 `hidden` 属性，且全局保证它生效。** `style.css` 必须有 `[hidden] { display: none !important; }`。任何给元素设了 `display` 的选择器（`#panel label { display: flex }`、`.row { display: flex }`）都会盖住浏览器自带的 `[hidden]`，已经踩过两次（T49 的 `.row[hidden]`、UX-1 审计发现的 `#manual-row`）。

### 5.4 状态行

- 状态文字（`.hint`）只写当前有意义的事；没事可说时隐藏整行，不留空行。
- 更新节流到 ≥ 250 ms、文字不变不写 DOM（现状已这样做，保持）。
- 面向用户的状态行里**不出现开发者数字**（GPU ms、预算、reason 代码）；这些进开发者区。

## 6. 默认值

- 默认值必须能让**第一次打开的普通用户看到最好看的画面**：连续航程开（VOY-DEFAULT）、画质自动、地面精度自动、真实地理数据开、人眼式自动曝光开、声音关（浏览器限制）、奇观关、小地图关。
- 默认值写在控件描述里（`default`），index.html 里的 `value=` / `checked` / `selected` 与之同源（框架渲染），不再两处各写一份。
- 回归场景的 `DEFAULTS`（`scripts/scenarios.mjs`）是测量用的确定性默认，**与用户默认可以不同**（例如测量时连续航程关），两者差异在场景表注释里写明。

## 7. 记忆（localStorage）与复位

### 7.1 记什么

| 记 | 键 | 理由 |
| --- | --- | --- |
| 连续航程开 / 关（只记用户关过） | `voyage.continuousJourney`（VOY-DEFAULT） | 用户明确的偏好 |
| 声音：音量、空调、提示音、钢轨接缝 | `voyage.sound`（现有） | 偏好；**开关本身不记为自动开**，浏览器要求用户手势，记住「上次开着」时只在面板上提示「点一下开启声音」 |
| 地面精度 | `voyage.groundRes`（现有） | 下次载入生效，必须记 |
| 座位、视角、座位相对机翼、舱等、舱内灯光 | `voyage.pref.view`（新） | 观看偏好 |
| 面板：隐藏、各区折叠、开发者区开关 | `voyage.pref.panel`（新） | 界面偏好 |

### 7.2 不记什么

- **画质档**：每次载入从「自动」起步（PERF-5 定，不改）。
- **时间、日期、天气、云参数、高度、航向、起点**：属于「此刻的场景」，连续航程开着时本来就在变；记住反而让人以为坏了。
- **开发者动作**（召唤奇观、立即到达、手动 EV）。
- 奇观的「已出现记录」`voyage.wonders.seen` 是系统数据不是偏好，不归面板管，也不被「恢复默认」清掉。

### 7.3 规则

1. **优先级**：URL 参数 > localStorage > 默认值。URL 强制的这一次**不写** localStorage（VOY-DEFAULT 的做法，推广）。
2. **只记用户亲手的操作**：`event.isTrusted` 为真才写（VOY-DEFAULT 的做法，推广；否则回归脚本在共享浏览器里会改掉用户的偏好）。
3. 键名统一前缀 `voyage.`，结构化的值带版本号（`{ v: 1, ... }`），读到不认识的版本就当没记过。
4. 所有读写包 `try / catch`（隐私模式拿不到 localStorage），失败就按默认。
5. **复位**：面板页脚「恢复默认设置」清空 7.1 表里的偏好键（不清 `voyage.wonders.seen`、`voyage.bootTimings.v1`），并立即把控件与状态设回默认（不需要刷新；地面精度照常「下次载入生效」）。每个区的摘要行右键 / 区内「复位本区」按钮只复位本区。滑条双击复位单项。

## 8. 快捷键与可访问性

### 8.1 快捷键表（唯一真相源，面板 `?` 帮助里列出）

| 键 | 作用 | 范围 |
| --- | --- | --- |
| `H` | 隐藏 / 显示面板 | 全局 |
| `Z`（按住） | 聚焦观察（放大，松开还原；等价于在画面上按住左键不动约 0.18 s）；倍率在开发者区调 | 全局（输入框聚焦时不触发） |
| `Shift+D` | 显示 / 隐藏开发者区（亦可 `?dev`） | 全局 |
| `B` | 进入 / 退出背景板模式 | 全局 |
| `Esc` | 退出背景板模式；关闭帮助 | 全局 |
| `M` | 声音开关 | 全局（背景板中也有效） |
| `N` | 调试小地图 | 开发者区开着时 |
| `←` / `→` | 左 / 右转 5°（`Shift` 15°） | 飞机模式 |
| `?` | 快捷键帮助 | 全局（新增） |
| `Shift + D` | 开发者区显示 / 隐藏 | 全局（新增） |

规则：

- **单字母快捷键一律用同一个守卫函数** `isTypingTarget(e.target)`（input / select / textarea / contentEditable 返回真），以及不带 `Ctrl / Alt / Meta`。现状 `H` 没有守卫、`B` 只查 input、`M / N` 查 input + select、方向键查全四种，不一致。
  - 补充（UX-1a 实施时定，协调者采纳）：守卫只拦**会接收字母的**输入（文本 / 日期 / 数字框、select、textarea、contenteditable）；复选框、滑条、按钮不拦——否则点完「声音」复选框再按 M、拖完滑条再按 H 都失灵。带 Ctrl / Alt / Meta 的组合一律不拦截。
- 新增快捷键先查本表，不许与浏览器常用键（`Ctrl + 任意`、`F5`、`Space` 滚动）冲突；加进表里。
- 快捷键在对应控件标签旁以 `<kbd>` 显示，并写进 `title`。

### 8.2 可访问性底线

- 所有可交互元素有可见的焦点环（`:focus-visible` 用 `--accent` 2px 描边）；现状没有自定义焦点样式，半透明深底上原生焦点环几乎看不见。
- 分段按钮：`role="radiogroup"` + 子项 `role="radio"` + `aria-checked`；开关：`role="switch"`；现状的「按钮 + `.on` 类」对读屏器不可见，至少补 `aria-pressed`。
- 滑条带 `aria-valuetext`（与 `output` 文字相同，例如「拉下 60%」）。
- `#panel` 加 `aria-label="控制面板"`；分区用 `<details>` 自带语义。
- 点击目标：桌面 ≥ 24×24 px，触屏（`pointer: coarse`）≥ 40×40 px。
- **对比度**：面板底是半透明的，窗外是亮天空时背景会变亮。正文与底色的对比度按「最坏背景 = 正午白云」算要 ≥ 4.5:1，次要文字 ≥ 3:1。调法：提高面板底不透明度（≥ 0.82）或给 `--muted` 提亮；审计里有实测。
- `prefers-reduced-motion`：关掉面板和提示的淡入淡出（画面本身不受影响）。

## 9. 布局：小窗、窄屏与遮挡

- **桌面（宽 ≥ 900 px）**：面板靠右上，宽 280–300 px；**高度不超过视口的 70%**，超出部分在面板内滚动；默认折叠后的高度目标 ≤ 55% 视口（1600×1200 下 ≤ 660 px）。面积占比 ≤ 20%。
- **小窗（600–900 px 宽，或高 < 700 px）**：面板默认只显示标题栏 + 「此刻」+ 观景区，其余折叠；宽 260 px。
- **窄屏 / 手机（宽 < 600 px）**：底部抽屉（bottom sheet），**默认收成一条 48 px 的把手**（显示「此刻」一行 + 展开按钮），展开后 ≤ 40% 视口高；必须有可点的收起按钮（手机没有 `H` 键，现状手机上唯一收起途径是背景板模式）。
- 舷窗在画面中央，面板**不得覆盖以视口中心为圆心、半径 = 短边 30% 的圆**；窄屏抽屉展开时画面可以整体上移（改 canvas 视口）而不是被盖住（这一条是方向，落地另议）。
- 面板外的叠层（小地图左下、字幕底部中央、背景板提示底部中央）不与面板重叠；新叠层先在这里登记位置：

| 叠层 | 位置 | 尺寸 |
| --- | --- | --- |
| 面板 | 右上 | 见上 |
| 调试小地图 | 左下 | 约 280×300 |
| 火车字幕 | 底部居中，距底 72 px | 单行 |
| 背景板提示 | 底部居中，距底 24 px | 单行 |
| 软件渲染提示 | 顶部居中 | ≤ 760 px 宽 |

## 10. 控件复用框架（建议，接口草案，不含实现）

### 10.1 目标

现在加一个控件要改三处（`index.html` 写 DOM、`ui.ts` 绑定、`main.ts` 或 `state.ts` 接状态），默认值写两遍（HTML `value=` 与 state 初值），记忆、复位、URL 参数、接管显示各自手写（`audio.ts`、`quality.ts`、VOY-DEFAULT 三套记忆代码）。框架把这些收成**一条声明**。

### 10.2 接口草案（`src/ui/panel-kit.ts`，TypeScript 类型示意）

```ts
type Tier = "user" | "advanced" | "dev";
type SectionId = "view" | "voyage" | "weather" | "sound" | "quality" | "dev";
type Effect = "instant" | "gradual" | "nextLoad";
type Override = "lock" | "nudge" | "pause";

interface Owner { by: string; override: Override; reason?: string } // 例：{ by: "连续航程", override: "nudge" }

interface BaseSpec<V> {
  id: string;                 // = DOM id，脚本契约，不许改
  section: SectionId;
  tier: Tier;
  label: string;              // 2–6 字，不带括号
  hint?: string | ((ctx: Ctx) => string);   // 控件下方一行
  title?: string;             // 悬停说明
  shortcut?: string;          // 登记到快捷键表，自动显示 <kbd>
  default: V | ((ctx: Ctx) => V);
  effect?: Effect;            // 默认 instant
  persist?: { key: string; version: number };   // 不写 = 不记忆
  url?: { param: string; parse: (s: string) => V | undefined }; // URL > 记忆 > 默认；URL 生效时不写记忆
  apply: (v: V, ctx: Ctx, why: "user" | "script" | "restore" | "reset") => void;
  commit?: (v: V, ctx: Ctx) => void;         // 滑条松手 / 昂贵副作用（snapAll、重建）
  read?: (ctx: Ctx) => V;                    // 系统驱动时的实际值；框架 4 Hz 刷新显示
  owner?: (ctx: Ctx) => Owner | null;        // 被接管时显示「自动」并按 override 处理手动输入
  disabled?: (ctx: Ctx) => string | null;    // 返回禁用原因（必填原因），null = 可用
  visible?: (ctx: Ctx) => boolean;           // 例：钢轨接缝只在火车模式显示
}

type ControlSpec =
  | (BaseSpec<boolean> & { kind: "switch" })
  | (BaseSpec<string> & { kind: "segmented"; options: Opt[] })
  | (BaseSpec<string> & { kind: "select"; options: Opt[] | ((ctx: Ctx) => Opt[]); groups?: boolean })
  | (BaseSpec<number> & { kind: "range"; min: number | ((ctx: Ctx) => number); max: number; step: number;
                          format: (v: number) => string; valueText?: (v: number) => string })
  | (Omit<BaseSpec<never>, "default" | "apply"> & { kind: "action"; run: (ctx: Ctx) => void; label: string });

interface Opt { value: string; label: string; title?: string }

interface SectionSpec { id: SectionId; title: string; summary: (ctx: Ctx) => string; defaultOpen: boolean; tier: Tier }

interface Panel {
  mount(root: HTMLElement, sections: SectionSpec[], controls: ControlSpec[], ctx: Ctx): void;
  get(id: string): unknown;
  set(id: string, v: unknown, why?: "script"): void;   // 给 applyScene：等价于设 value + 派发事件
  resetAll(): void; resetSection(s: SectionId): void; reset(id: string): void;
  snapshot(): Record<string, unknown>;                  // 给 dev-browser 截图 JSON 的 panel 字段
  shortcuts(): { key: string; label: string }[];        // 快捷键帮助
}
```

框架负责：渲染（按 kind 生成 DOM，id 不变）、分区与折叠（`<details>`）、默认值（单一来源）、优先级 URL > 记忆 > 默认、`isTrusted` 才写记忆、双击复位、默认值刻度、`aria-*`、`read` 轮询与拖动 / 聚焦时不抢、`owner` 的「自动」标记与三种 override、`disabled` 原因进 `title`、快捷键统一守卫、`snapshot()`。

控件描述只写**业务**：`apply` 里是现在 `ui.ts` 各 `addEventListener` 回调的内容。

### 10.3 示例（示意）

```ts
{ kind: "range", id: "wind", section: "weather", tier: "user", label: "海面风速",
  min: 0, max: 20, step: 1, default: 7, format: (v) => `${v} m/s`,
  apply: (v, c) => { c.state.wind = v; },
  read: (c) => Math.round(c.state.wind),
  owner: (c) => c.director.active ? { by: "连续航程", override: "nudge" } : null }
```

### 10.4 迁移步骤（每步一个任务，可独立验收，均不改控件 id / 选项 value）

1. **契约冻结**：把现有控件 id、选项 value、`applyScene` 用到的事件类型列成表，写进 `scenarios.mjs` 头部注释；`check:glsl` 同类的脚本加一条断言「场景表用到的 id 在 index.html 里都存在」。
2. **框架骨架 + 试点**：新建 `src/ui/panel-kit.ts`（类型、`range` / `switch` / `segmented` / `select` / `action` 渲染、双击复位、aria、`isTypingTarget`），先迁「声音」区（控件少、已有记忆，最能验证 persist 与 `audio.ts` 现有键兼容）。验收：截图与改前一致；`voyage.sound` 旧值能读。
3. **分区与分层**：`<details>` 分六区 + 开发者区门控（`?dev`、`Shift + D`），按第 2 节挪位置；`index.html` 里的控件还可以暂时是静态的，只挪到对应 `<details>` 里。
4. **逐区迁移**：观景 → 画质 → 航程 → 天气，每区一个任务；`ui.ts` 的 `setupXxxUi` 逐步变成控件描述数组。
5. **接管协议**：给导演 / 天气导演补 `read` 与 `owner` 需要的只读接口（例：`director.weatherOwned()`），天气区接上 `pause` 语义（需要导演支持「手动天气」开关，另派）。
6. **记忆统一**：`audio.ts`、`quality.ts`、VOY-DEFAULT 的记忆代码改走框架 `persist`，旧键原样兼容（不做迁移写入，读旧键即可）。
7. **收尾**：`index.html` 的 `#panel` 只剩空壳和页脚署名；`#panel` 相关样式从 `index.html` 内联 `<style>` 搬回 `style.css`；README「模块地图」更新。

每步都是**热点文件**（`ui.ts` / `index.html` / `style.css` / `main.ts`）上的改动，按 DEV_SOP「一波里每个热点文件最多分给一个任务」排，不与其他碰面板的任务并行。

## 12. 验收截图的做法

面板默认被截图工具隐藏（`applyScene` 给 `#panel` 加 `hidden` 类）。要截面板，用场景的 `js` 字段去掉它并滚动：

```
node apps/voyage/scripts/dev-browser.mjs shots --port <端口> --angle d3d11 --respect-lock \
  [--viewport 1280x720] --out tmp/screenshot/<任务> --scenes-file <场景文件.json>
```

场景 `js` 示例：`const p=document.getElementById('panel');p.classList.remove('hidden');p.scrollTop=0;` 之后返回 `p.scrollHeight`、`p.getBoundingClientRect()` 等尺寸，写进截图 JSON 的 `info`。UX-1 用的场景文件在 `tmp/screenshot/ux1/scenes-desktop.json`、`scenes-small.json`（临时目录，需要时照着写）。截图工具默认把画质档固定成「高」，状态行会显示「高（固定）」，属正常。
