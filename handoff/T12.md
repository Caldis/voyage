## 对照真实航拍照片的结论

- 卷云：真实的毛卷云 / 钩卷云是顺高空风的细丝、成带状分布、末端甩成马尾，从下面看是白色半透明、透出蓝天。旧版是灰色不透光的团块（光学厚度几十）。现在是顺风的丝缕、带状、半透明、白，末端渐细；平视（10.7 km 看 11.5 km 的卷云）是一条掠射的薄纱带。
- 银边：真实逆光的积云顶和薄边被照透发金 / 发白、云体背光面暗。旧版 sunset-wing 整团灰褐剪影；现在云顶一圈金亮、底部暗，storm-dusk 的积雨云塔身和砧边有清楚的银边。
- 云底：真实积云底大体平，但明暗斑驳、有垂下的絮团。旧版从下面看是一整块光滑的灰板；现在是明暗相间的絮团。

## 已完成

1. **逆光积云没有金边——根因是受光步进后 3 步用的「不带细节」的大形太胖**（写在前面的假设被推翻）：
   - 先怀疑 Beer-Powder 压暗薄边、前向相函数不够尖：去掉 powder / 加 g = 0.9 波瓣，sunset-wing 几乎不变（`T12-v1.mjs`、`T12-v2.mjs`）。
   - 受光光学厚度置 0（`od0`）云立刻金亮 → 问题在受光的光学厚度。分段：只留前 3 步（带细节）金边回来，只留后 3 步（不带细节）≈ 原图（`T12-v3.mjs`）。
   - 不带细节的层状云密度完全不侵蚀，再 ×3.5 饱和：比画出来的云胖一大圈的实心。太阳 1.7° 时光线平着穿过整层云，几乎每个样本都被邻居的「胖影子」挡住，整团云是灰褐色剪影。
   - 修法：不取细节时按细节噪声均值侵蚀（`remapc(d, 0.275, …)`，不取纹理）。效果与后 3 步也带细节（多 3 次取样）几乎一样（`T12-v4.mjs`）。正午几乎不变；150 km 外不带细节的远云也和近处一样瘦了。
2. **银边的前向衍射峰**：水滴散射约一半是几度内的衍射峰，按 delta 缩放它只受约 1/4 消光。多次散射求和前加一项 `0.6·hg(cosT, 0.9)·exp(−0.25·od)`；粉末效应在朝太阳看时淡出（cosT 0.3–0.9）。backlit-cu（3 km、太阳 12° 在前方）云顶边缘明显亮一圈；storm-dusk 的积雨云塔身、砧边出现银边。
3. **卷云**：拉长 14 倍、横向压窄 1.8 倍、覆盖阈值抬高、密度不饱和（半透明）；成片范围顺风压缩 3 倍（带状）；丝缕按 ~50 km 缓慢蜿蜒、越往下被风切变甩向一侧（马尾 / 钩）；环境光下限 0.6（薄冰云底下看得到大半个天）。
4. **云底絮团**：高度剖面的输入按 0.4 km 小单体（nA.a）和几公里起伏（fbmB）上下错开 ±几十到一百米；云底最下面一两百米侵蚀阈值加大。base-up / base-level 从光滑灰板变成明暗相间的絮团。
5. **卷云做成云步进的 `#define CLOUD_CIRRUS` 变体**（`marchCirrusMat`）：卷云代码写成不分支算术或按 uniform 分支，积云场景云步进都落到慢一档（noon-cumulus 0.40 → 0.50 ms、typhoon-bands 页面内 +20%）；逐项去掉任何一处都会回落（`T12-mkvar4.mjs`，和 W00 同类）。云影 / 探针程序直接带卷云代码。卷云变体在要画卷云时、或启动后约 300 次 probe 时后台编译；`cirrus-noon` 场景的 js 等它编好。

## 还不够好

1. 卷云变体第一次用要后台编译（d3d11 离线 FXC 约 14 s，有缓存后很快）；编好之前卷云按普通层状云画（团块）。启动后约 300 次 probe 会预热。
2. 卷云只有一层、全局一个云型：卷云和下面的积云不能同时出现（真实航路上最常见的组合），需要第二层层状云，是更大的改动。
3. storm-dusk 里低处的积云被落日照成亮橙色（逆光 + 前向峰）。物理上太阳还在它们的地平线以上，但真实日落时低处大多已在几百公里外其他云的影子里（T45「还不够好」同一条）。
4. 云底的絮团是按高度剖面错开做的，近处（几百米内）仰视时碎絮不够「挂下来」；要更像碎积云需要云底以下单独的碎云带。
5. 卷云没有做冰晶相函数（晕、幻日由 T17 另画）。
