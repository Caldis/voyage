## 踩过的坑
- FXC 对常量上限的循环、以及被多处调用的函数（`sampleGround`、`keyLight`、`cloudShadow`）会逐处内联展开，冷编译线性变长，严重时 CONTEXT_LOST，还会让共享浏览器禁用 WebGL（`browser_close` 后重开恢复）。
  - 识别：用冷启动脚本二分，把某段用 `#if 0` 包住再测。
- rAF 帧时间被垂直同步锁在约 6.2 ms，要用 timer query 测 GPU 时间。
- 在线性空间给影像分类会分错；水体遮罩阈值 0.5 会抹掉细河（改成 0.3）。
- scratchpad 里别把脚本命名成 `bisect.py`：会遮住 Python 标准库，PIL 导入时崩。
