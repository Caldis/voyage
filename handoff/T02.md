## 协调者需要在 main.ts 接入
```ts
import { GroundDetailVariant, createSceneMaterial } from "./render/scene";
const groundDetail = new GroundDetailVariant(sceneMat);      // 紧跟 createSceneMaterial 之后
pass.render(state.groundOn ? groundDetail.pick(renderer, state.altitudeKm) : sceneMat, hdr);  // 替换 pass.render(sceneMat, hdr)
```
（`altitudeKm` 是海拔；离地高度更准，但 clipmap 目前没有「飞机正下方地形高度」的 CPU 接口。T18 定了陆地上空离地下限约 2.5 km，门限 4 km 足够。）

## 踩过的坑
- 常量次数的大循环会被 FXC 整个展开：冷编译翻倍，严重时 CONTEXT_LOST，还会让共享浏览器禁用 WebGL（`browser_close` 后重开恢复）。
- rAF 帧时间被垂直同步锁在约 6.2 ms，要用 timer query 测 GPU 时间。
- 在线性空间给影像分类会分错；水体遮罩阈值 0.5 会抹掉细河（改成 0.3）。
