## 坑

- Windows 上用 Python `open(...,"w")` 写文件会写成 CRLF；仓库 `.gitattributes` 会在提交时转回 LF，不影响结果，但 diff 前要知道。
- 浏览器锁竞争激烈；`until mkdir ...; sleep 15` 的等待会一直抢不到，改成每秒试一次。
- 共享浏览器里别人的页面丢了 WebGL 上下文后，Chrome 会禁用 WebGL（`GL_VENDOR = Disabled`），要 browser_close 再重开。
- 抢到锁后当前页面可能停在别人的端口，回归脚本沿用当前页面的端口 → 先 navigate 到自己的端口再跑。
