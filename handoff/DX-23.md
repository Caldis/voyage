## 设计要点（接手必读）

- **变体格式 ab / flight 共用**：`materials`（来源 `current` / `base` / `base:<另一材质>` / `file:<路径>`，一次可换多个材质）、`patch`（键可逗号列多个材质）、`defines`、`uniforms`（点号路径，数组走 `fromArray`）、`js`。每个变体前把**所有**变体碰过的材质原文 / defines / uniform 复原。`js` 改的东西不会自动复原——需要复原的状态写成 `uniforms`。
- **每帧都被主循环重写的 uniform（如 `uBoltIntensity`）用 `uniforms` 覆盖不住**（冻结时 renderFrame 仍在跑），要改它的来源或改着色器。
- `ab` 的预热判据：冻结时连续两张截图逐字节相同（本次所有截图 1 轮就稳定）；`--cloud-live` 时改成等 30 帧（DEV_SOP ③）。
- `flight` 的真值 = 同姿态静止时 `clouds.raw`（resolve 之前）等权平均，**不依赖 resolve 文本**（C12b 的 truth 变体靠替换 `TAIL_OLD`，C12b 合并后那段文本已经不存在，旧脚本直接失配）。`uFrame` 周期 64，`--truth` 取 64 的倍数；只对云外有意义。
- `flight` 全冻结（不是 cloudLive）：云只由脚本手动 `clouds.render` 推进，rAF 循环不插手，航迹逐位可复现。`live` 模式例外（解冻、真飞，只看统计量）。
- `ab` / `flight` 持测量锁（先等锁）。

2. **ab**（`handoff/DX-23-ab-jobs.json`，`--base 5291`，约 1.5 min）：
   - night-city（带地面，冻结后等瓦片 27.5 s，pending 0、CORS 0）：`master`（`exposure.finalMat` 换 master 原文）对 `cur` 逐像素 0；`chroma0`（`uNightChroma.x = 0`）平均差 0.148、最大 20.7、5182 像素 > 8，HSV 饱和 14.09 → 13.58、RGB max−min 8.82 → 7.58；噪声底全 0。
   - sunset-wing：`wingMat` 换 master 原文，截图与 `hdrWing` HDR 逐位 0 差；`benchWing(30)` 中位 0.503 ms 两边相同。
   - `--cloud-live`（noon-cumulus，`clouds.resolveMat` 三变体）：噪声底 cur 0.159、master 0.147；`blend012`（固定 blend 0.12）自身两轮差 0.277、对角差 2.95 → 3.02。
