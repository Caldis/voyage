## 做了什么

一整块从海面 / 云海里竖起来的台地（天幕层，解析几何，没有步进）：

| 部件 | 现在 | 与研究文档 §3.6 候选 3 的差别及理由 |
| --- | --- | --- |
| 形态 | 主块：长 280–600 km、宽 90–220 km 的凸多边形台地（≤16 个顶点，边是几十 km 一段的崖面），岩壁后仰 1.5–7°；主块前面挂 2–4 块岬角 / 离岸孤台（≤6 个顶点）：贴着主壁的岬角后仰 8–22°（像从墙上伸出来的山脊），孤台 / 高出主壁的「角」是陡壁 | 研究文档写的是「悬空平台 + 撑柱、云间层」。按简报改成从海面拔起的岩墙 / 台地（天幕层）：200–300 km 外云间层包围盒装不下，而且「竖起来的大陆」本身比悬空平台更「看得到」；层叠的岬角剪影一层比一层蓝，是这次最有效的尺度线索 |
| 尺寸 / 位置 | 顶沿 30–90 km（主峰偏向近端的船首），船首在 200–290 km 外，主块斜着往地平线退去（长轴与视线夹 20°–60°） | 简报 30–80 km / 200–400 km：近端放 200–290 km 才够「压」过来；远端自然伸到 400–600 km、脚沉到地平线以下只剩顶沿 |
| 细节三级 | 轮廓（崖面、层叠岬角、顶沿起伏 + 孤峰 + 瀑布口缺口、风化抖动的端棱）→ 分段（2.2–4.5 km 的主层理带倾角 / 层厚不均 / 有的段清楚有的段是整块岩体，缓坡层是受光台阶；15–40 km 的扶壁与 3–7 km 的冲沟按噪声摆法线；脚下崩塌锥；瀑布）→ 纹理（1.5 / 4 km 斑驳、沙漠漆挂痕、色斑；按足迹淡出） | 细层与 0.9 km 细竖纹做过，远看和层理交成方格（玻璃幕墙），去掉了 |
| 云交互 | 近处真实云海挡住脚；岩壁挡住比它远的真实云（`gWonderCov / gWonderT`，`clouds.ts` 的 depthOn 加了 `uContOn`）；脚下一圈堆起来的云墙；约 2/3 的大陆在 8.5–12.5 km（我们的高度）挂一段段贴壁云带；瀑布落差十几 km 后化成雾带；一架同高度航班的航迹云横在岩壁前（90–160 km） | — |
| 大气 | 物理空气透视；400 km 以外按平均消光外推 | M6（上段 / 下段对比）正午 5.1、云海 5.7、夜 3.9、黄昏 2.4 |
| 黄昏 | penumbra.glsl.ts 的地影半影（`contShadowT`）：顶沿被染成橙红、下段在地影里是比天空暗两成的剪影 | — |
| 夜 | 挡住星空（`gStarVis`）、挡住月盘 / 太阳圆盘的一整块剪影，月光下受光面淡淡可见 | 没有灯（自然地貌） |
| 随机性 | 形状、岬角个数与种类、高度剖面、岩性（红砂岩 / 花岗岩 / 玄武岩 / 石灰岩）、层理厚度与倾角、冲沟间距、瀑布、冰盖、云墙 / 云带、航迹云，全按种子 | — |

## 遗留（按「先大后细」）

1. **OWV 冷编译比 OW 高约 10–15%**（OWP 比 OW 低 10%）。它不在关键路径（只在垂直大陆在场时后台编，浮现本身 120 s），GPU 在场增量达标。逐项撤回（`WS09-fxc-variants.mjs`）：表面花纹 −35%、顶沿求值 −19%、贴壁云 −17%、航迹云 −15%、瀑布 −14%，都是看得见的部件；要压到 +10% 以内最省事的是去掉贴壁云带（保留云墙）或把航迹云换成更简单的直线。建议波次收尾安静窗口复测后再定。
2. 正午顺光时岩壁偏白、偏「磨砂」（物理上顺光的岩面比天空亮，空气透视又冲淡了反差）；黄昏、夜、侧光时最好看。若用户想要更「实」，可以把默认岩性再压暗或提高斑驳。
3. 岬角 / 台地都是直边多边形，近看端棱靠噪声抖动，崖面仍是平面（没有真正的凹凸几何）；顶面从下面看不到，没做。
4. 没做投在云海上的长影（研究文档 WS06 的「巨影」），逆光时会很壮观；需要在云合成处按云深度判影，建议看图后再定。
5. 顶沿高度按局部切平面给，远端 400 km 外实际海拔会比设定高几 km（地球曲率），视觉上无关紧要。
6. 夜里没有任何灯（自然地貌）。
