## 变体机制
- 同一份舱内合成源码（scene.ts 的 SCENE_FRAG），差别全在预处理层：`#define CABIN_CLASS_ECONOMY` 时
  - `fabric.glsl.ts`（从 741fa11^ 取回 T06 版本）整段包在 `#ifdef CABIN_CLASS_ECONOMY`；
  - `cabin-leather.glsl.ts` 与 seats 的 `seatSeams` 包在 `#ifndef`；
  - `cabin-shading.glsl.ts`：饰面反照率常量、`cabinMoodScene`（冷白主灯、无氛围灯、睡眠档一点冷蓝夜灯）、侧壁橘皮纹 + 收敛的使用痕迹 + 6 颗小螺丝、窗罩积灰 / 油光、旧橡胶密封条、遮光板无金属拉手；
  - `seats.glsl.ts`：经济舱塑料背壳（小桌板缝、锁扣、轻手印）+ 织物 / Charlie sheen；
  - `cabin-reflect.glsl.ts`：倒影里对面侧壁 / 行李架的反照率跟着换。
- `scene.ts` 的 `CabinClassVariant`：商务舱 = sceneMat 本身（启动批次里编的就是它，冷启动只编这一套）；
  面板选经济舱时 `compileAsync` 后台编译（编译前 `setRenderTarget(hdr)`，单输出），编好前继续画当前舱等，
  编好再切；resolve 后取 `currentProgram` 调 `getUniforms()` 检查 `diagnostics.runnable`，失败留在原舱等、面板提示。
  编过的变体保留，来回切不再编。两个材质共用一份 uniforms。
- `main.ts`：每帧 `cabinClass.pick(renderer, state.cabinClass)`；`exposure.finalMat.uniforms.uCabinRefAlbedo` 按当前**实际显示**的舱等换
  （T28 色适应要除掉饰面本色，浅灰塑料不能按暖白饰面算）；面板 `#cabin-class-status` 显示「准备中…」/「编译失败」。
  调试句柄 `__voyage.cabinClass`（`shown`、`status(c)`、`lastCompileMs`）。
- 回归：`scenarios.mjs` / `regression.playwright.js` 的 DEFAULTS 加 `"cabin-class": "business"`，applyScene 等目标舱等上屏再截图；新场景 `economy-ahead`。
- `lint-shaders.mjs` 加 `scene-economy` 程序（语法 + 重名 + sampler 都查；shader-budget 也自动覆盖到它）——这个文件不在归属清单里，改动 3 行，请协调者确认。
