## 画面

| 部件 | 做法 | 看点 |
| --- | --- | --- |
| 雾（云间层介质） | 城区椭圆（半长轴 27 km）里按高度指数衰减的雾，标高 0.35–1.0 km 随地点起伏（塔脚下热岛把雾顶起），云形状噪声做团块与疏处；城外一圈稀薄霾裙 | 被前面的云挡、挡住身后的云（W00 接口） |
| 灯海照雾 | 地面是亮度 Lg 的朗伯发光面，雾里 emit = σ·反照率·Lg/4，乘「被下面的雾挡掉多少」（厚处暗、薄处亮，所以有体积感）；Lg 按街区 / 公园 / 蜿蜒的河 / 塔脚热区 / 暗的工业区变化，少数片区冷青 | 暗橙对冷青；reveal 让片区先后亮起来 |
| 光穹 | 城上空 0.6–4.5 km 的稀霾被灯海照亮（解析，沿视线 3 点） | 雾顶上方一层淡橙光 |
| 两座阶梯金字塔 + 四座退台高塔 | SDF（三段同坡截头四棱锥 / 三层方盒），反照率 7%，夜里只被下方的雾照一点；斜面上极稀的暗橙灯带（6% 格子亮），塔顶冷白灯、高塔顶红色障碍灯 | 雾里的剪影；白天淡灰 |
| 火炬 + 烟柱 | 工业区 6 根烟囱，各自 5–11 s 周期「喷一下」（0.25 s 冲起、1.2 s 衰减，有的周期不喷），火舌是竖长的解析光斑；烟柱是顺风弯的介质，火光按 exp(−d/L)/(1+d²) 照亮烟底和附近的雾 | 周期性映红烟底 |
| 探照光束 | 3 束，60/90/120 s 缓慢扫动；单次散射线积分闭式解（高斯截面，像素足迹展宽、能量守恒），雾里 σ 大所以亮、雾上霾里淡，6.8 km 前渐隐 | 穿过雾时最明显 |
| 雾下车流 | 与 y = 0 平面求交：街区颗粒（按足迹选 mip）+ 3 族缓弯、分段断续的干道，车流虚线沿线平移、足迹大于周期时振幅淡出 | 透过雾的疏处若隐若现 |

白天：自动出现**只在夜里**（研究文档 C6：太阳 < −12° 权重 3，−12°..−6° 权重 1，更亮为 0）。手动召唤白天照样能看：一团偏黄褐的霾（雾反照率 (0.72, 0.56, 0.33)，被太阳照）与巨塔的淡灰剪影（`tmp/screenshot/W02/final/fogcity-day.png`）。取舍：白天没有「灯城」，只剩霾与塔——这样白天也不突兀，但不主动出现。

## 已知问题 / 留给之后

- **夜里的颜色偏「暖米 / 桃橙」，不够浓的橙**：自动曝光 + 浦肯野 + AgX 三者夹出来的（见 README 坑点第一条）。黄昏同参数是浓橙。要夜里更橙，得在 exposure.ts 里给「大面积暖色自发光」放宽浦肯野或调 AgX（不在本任务归属）。
- 95 km 时城心接近截白（p99 约 220/255），近看（72 km）不截。
- 城市辉光没有照亮它上方的云底（需要改 clouds/*：步进里加一项按奇观灯海的向上照度，建议接口：`wonderUplight(pW)` 由奇观种类提供、云步进变体里调用一次）。
- 放置不看「是否在城市上空」（WonderContext 没有地面夜光信息），海上 / 陆上都可能出现；陆地山区时雾会盖在山上（包围盒只按海平面截）。
- 白天手动召唤时塔直接出现（reveal 只驱动雾与灯，不驱动塔）；自动出现只在夜里，塔本身是暗的，不会「突然出现」。
- 调试 / 截图用 `seed` 固定布局；自动出现时每次随机（朝向、河道、雾纹、火炬节奏、光束相位）。

## 怎么复现

```bash
cd apps/voyage && npx vite --port 5202 --strictPort --host 127.0.0.1
bash apps/voyage/handoff/W02-shots.sh 5202 tmp/screenshot/W02/final d3d11 near,cloud,day,dusk
node apps/voyage/scripts/dev-browser.mjs shots --port 5202 --only wonder-fogcity-night,noon-cumulus --out tmp/screenshot/W02/final
cd apps/voyage && node handoff/W02-passes.mjs --port 5202 --only wonder-fogcity-night,noon-cumulus --variants handoff/W02-variants.json --frames 30
node handoff/W02-cold.mjs --port 5202 --repeat 2
node handoff/W02-flicker.mjs --port 5202
```
控制台：`__voyage.wonders.enabled = true; __voyage.wonders.trigger("fogcity", { forwardOffsetDeg: 0, distKm: 80, reveal: 1 })`，等 `__voyage.clouds.wonderLayerState === "ready"`（d3d11 冷约 15 s）。
