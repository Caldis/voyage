## 做法

命中样本在表面以下的深度 D ~ U[0, L]，浓云像素的亮度只由表面以下十几到几十米决定，受光随深度凸下降 → 期望偏暗（Jensen）。C10 的二分顺带把样本收到了表面附近。

```glsl
// 进云那一步（i > 0、上一步空白；天气程序里 stormW < 0.5 && fine == 0）
float kv = σ · max(−rd·up, 0.05) / max(sun·up, 0.05);       // 受光随沿视线深度的衰减率（云顶近似水平）
odCut = min(0.4·L·kv, 3) · smoothstep(1, 3, σL);            // 薄步（σL 小）本来就是区间的无偏估计，不减
// 6 步受光步进里记下前 3 步的 odNear，然后
od −= min(0.5·odNear, odCut / CLOUD_EXTINCTION);
```

σ、区间、不透明度都不动 → 云边宽、α 分档与 C10b 逐位一致（下表）。雷暴 / 台风的受光（另一支）不动。

# GPU：mkjobs 生成 cur,cur2,c10b 后给每个 job 加 {"name":"master","materials":{"clouds.marchMat":"base"}}
