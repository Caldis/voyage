## 测量方法

`handoff/STROBE-FLASH-live.mjs`（私有 d3d11 headless，1600×1200，voyage=0，闪电按住）：
- 飞行中每个 rAF 紧跟主循环 readPixels 整个画布（不截图），按 main.ts 的时序（`ts % 1.1` 的两个 50 ms 窗）给每帧标「在闪」。
- 区域：曝光合成的 `uDebugMask` 分舱内 / 窗内；窗内按离灯芯的屏幕距离分近 < 80 px、中 80–250、远 > 250（`job.lamp` 固定灯芯位置，两个端口对照时分区一致），另给整窗。
- 跳变 = 每段频闪里区域均值的最大值 − 该段开始前 3 帧的均值（显示 0–255 的 Y，各段平均）。
- 另记：远区爆闪像素（闪亮帧比闪前帧亮 ≥ 8 级的占比）、近中区变暗像素（T48c P2-1 口径：闪光各帧都比闪前暗 ≥ 4 级，4× 下采样像素数）、
  非频闪帧的闪烁像素（去掉频闪帧及其前后帧，时间二阶差 > 16 的帧占比 > 5%）、自动曝光适应值（窗外对数均值 o）在频闪段内的抬升。
- `shot: true` 变体：冻结 → 钉灭 30 帧 → `exposure.localDt = 0` 保持闪前状态 → 钉亮 → 截图（等价于飞行中频闪第一帧）。
- `probe: true` 变体：跑一段 js 打印返回值。`patch(材质, [[查找, 替换]])` 改着色器原文做消融 / 候选。

结论（按路径）：
1. **② 眩光（主因）**：频闪朝眼睛按各向同性 1500 cd 画灯芯，灯芯 530 kcd/m²；bloom 把 4% 能量按 1/θ² 宽尾巴铺开，灯周 256 px 处闪光的低通是场景自身的 40 倍（探针）。关掉眩光远区跳变 39 → 2。
2. **③ T48c 闪光份额不吃局部适应**：放大器。闪光那份眩光按原始曝光直出；让它吃即时局部适应（T48b）远区 39 → 27、中区 141 → 84，但会回到 T48c 要修的「频闪瞬间翼梢 / 灯芯变暗」。
3. **① 自动曝光**：晴空夜城只抬 0.03 档，不是爆闪的原因；**云中每闪一次抬 0.3–0.5 档**，闪完整窗先暗一截、按 2.5 s 慢慢亮回（1 Hz 呼吸）。
4. **④ 云雾散射**：旧版雾里用朝眼睛的满光强 1500 cd 各向同性地照雾；云中整窗 +180 级（纯白）。
5. **⑤ 窗玻璃 / 舱内反射**：舱内跳变 0–0.05 级（云中 +6 来自 ① 的适应），不是原因。
6. **其他（压小以后暴露的）T48c 粗网格方块**：把频闪压到合理亮度后，灯周出现 16–32 px 的亮方块——T48c 存粗格绝对扣除量 T、取 3×3 最小值、再给「亮了 6–12 倍」的格开例外，例外格以内整份不适应、以外被最小值削过；1/r² 的光晕在 16 px 一格上对不上。原来被整窗死白盖住看不见。

## 修法

1. `wingLampIntensity` 的频闪（i == 1）按 W-LAMP 给翼面用的同一套配光（`wingLampSurfI` 的 i == 1：朝外半空间、竖直集中在水平面附近、朝内漏光 0.15）。
   旧版照翼面按 0.15 漏光、照眼睛按满光强，自相矛盾；眼睛在灯的内侧，朝舷窗约 100–300 cd。
2. `wingLights` 画频闪灯芯时软上限 `I / (1 + night·I/STROBE_CORE_CD)`，`STROBE_CORE_CD = 30`，night = 太阳 −3° → −12° 由 0 到 1（白天不压，白天的白闪是防撞灯的用途）：**显示取舍，不是物理**。
   夜里灯芯怎样都是纯白，亮度只靠眩光显出来；按真实光强铺，50 ms 一闪整窗亮。上限取常亮航行灯正前方（40 cd）同量级：频闪读成翼尖一个刺眼的点 + 翼面被照亮（翼面照度仍按 `wingLampSurfI` 的真实光强，没动）。
   扫过 8 / 15 / 20 / 30 / 60：60 光晕仍 ~100 px 大；15 / 20 与 30 观感接近、远区再低 1–2 级，取 30 保住「最亮的点」。
3. 雾里的单次散射（频闪）：沿视线按角度 φ 积分云滴的前向散射相函数（Schlick 近似，g 0.85 → k 0.98），有初等原函数
   `k cosφ/(1 + k sinφ) + 2/√(1 − k²)·atan((tan(φ/2) + k)/√(1 − k²))`；两端 φ = atan(x) 的 cos / sin / tan(φ/2) 由 x 代数算，只剩一次 vec2 的 atan。
   前向那一半（眼睛和灯之间）拿灯朝内的漏光 0.15 × 竖直约 0.6 = 0.09，另一半按配光平均 0.2。侧向 90° 只有各向同性的约 1/8：远离灯的雾微亮、灯周一团亮雾。
   **已推翻**：① 各向同性 + 配光平均 0.2（云中整窗仍 +150，均匀发灰）；② 按「灯 → 视线最近点」方向逐像素取配光（十字形亮瓣）；
   ③ 12 点数值积分配光 × HG（平滑、云中 +101，但离线 FXC wing +11%、wing-wet +22%）；④ 闭式积分用 cos / sin / tan 三组三角函数（wing +4.5%）。
4. `Exposure.render`：已知闪光（`exposure.flash`，频闪 + 闪电）期间全局适应的 dt 乘 (1 − flash)，不前进。云中每闪一次的 0.5 档抬升 → 0。
5. T48c 粗网格改存**闪光份额** f = T / 当帧粗格亮度（B 通道），3×3 取最小值的是份额，最终合成用 f × 细低通当扣除量；删掉「6–12 倍例外」。
   份额在光晕里处处接近 1（探针：灯周 1–4 格 0.997–0.9998）、在光晕边缘随常亮光平滑下降，最小值不削峰、不再需要例外；运动差照样是孤立格、照样归零。
   不闪时 f = 0，最终合成走 T48b 原式，逐位相同。
   **试过没用**：3×3 开运算（腐蚀再膨胀）代替腐蚀——光晕的坡恢复了，但灯所在的例外格仍是一块方的；把频闪踢出 `exposure.flash`（按 T48b 即时适应）——没有方块、光晕更小，但近中区变暗像素 7 → 40–164（T48c P2-1 回来了）。

## 还不够好 / 建议

- 云中夜里仍是整窗明显的一亮（整窗 +95、窗边 +80）：单次散射 + 前向相函数下这是物理量级（σ ≈ 0.05/m，灯到舷窗 15 m），再压就要做显示上的取舍（例如闪光份额在云里也吃一部分局部适应）。
  真实航班在云中夜航常按 SOP 关掉频闪（反光晃眼），可以考虑「在云中自动关频闪」或面板开关，交协调者 / 用户定。
- 航行灯 / 尾灯的雾散射仍是各向同性相函数（只改了频闪）；统一成同一套前向散射会改变常亮的绿 / 红雾光，属于另一个任务。
- `STROBE_CORE_CD` 是显示取舍的旋钮：15 / 30 / 60 扫过，60 光晕仍约 100 px；要更「刺眼」可以 45，要更收敛可以 20。
