### 天梯（致敬《流浪地球 2》太空电梯）
| 部件 | 做法 | 什么时候看得见 |
| --- | --- | --- |
| 中继站 ×7 | 16 km 起按约 1.85 倍往上排（±8% 不规则），扁椭球（半径 0.9–3.1 km，第 3 个是大中继站），反照率 0.3；视线求交得法线，太阳 / 月亮直射 + 天光 + 下方地球反光 | 正午：线上一串浅灰的「碟」（底面被地球反光照亮、边缘被阳光照亮）；黄昏：地影以上的那几个是亮点；夜里：月光下的淡影 + 两端灯 |
| 面板闪光 | 平台边缘 16 块倾角各异的金属面板，约 1.5 分钟转一圈；半角向量对上某块面板的方位 / 倾角时，亮点落在朝相机那侧的边缘（铱星闪光的机制） | 白天 / 黄昏偶尔「闪一下」（每个站约 1 分钟一次，窗里 3–4 个站） |
| 舱体 | 上行（约 200 km/h）、下行（约 130 km/h）两条轨道，格子随机空着；长椭球，反照率 0.4；夜里一点白色航行灯 | 正午是线上的小亮珠，要盯一会儿才发现在动（0.2 px/s） |
| 稳定缆 ×6 | 从最低两个中继站斜拉到 18–24 / 40–52 km 外的海上锚点，半径 50 m（亚像素，按面积摊薄） | 夜里 / 黄昏背景暗时是几根极淡的斜线；正午几乎看不见（有意） |
| 海上系留平台 | 基座处又宽又扁的椭球（半径 8.5 km）+ 0.5 km 一格、三层的灯群（钠灯 / 白光混着） | 只在地平线干净时若隐若现；默认 370 km、云量 0.3 时被地平线上的云挡住（见「已知问题」） |
| 航标灯（节律） | 夜里：缆上每 30 km 一盏红灯，**全部同步**慢闪（2 s，缓起缓落）；白天：中继站两端高强度白色频闪，从下往上依次闪（4 s 一轮）。真实高塔就是白天白闪、夜里红闪 | 夜里、黄昏（地影里的下段有一串红点） |

| 部件 | 做法 | 什么时候看得见 |
| --- | --- | --- |
| 九欘 | 55–125 km 高处长出九根弯枝，`g(u) = 2u − u²`（根部斜出、梢部竖直），往外伸 12–38 km，越往梢越细 | 黄昏最美（整棵树冠被阳光照亮，像一束发光的枝）；白天、夜里是淡淡的枝影 |
| 云气缭绕 | 12–30 km 树干上挂着三圈云环（间隔不规则），远看是横在树干上、顺风拖向一侧的絮状云（旗云），圈间一层薄雾；反照率 0.8 | **白天最先被注意到的就是它**（地平线上方几道白色云絮，中间穿着一根细线） |
| 萤光（黄实） | 树冠一带稀疏的金色光点，缓慢上飘；夜里明灭，白天偶尔被阳光照到闪一下 | 白天是树冠一带零星的金色闪点；夜里是微光 |
| 众帝上下 | 沿树干升降的暖色光团（复用天梯舱体的轨道） | 夜里 |

### 可见性的物理说法（为什么现在白天看得见）
W00 查因：正午暗线与天空的对比 < 1/255——视线上的天空亮度几乎全来自线前面的空气，高处那段身后是太空。暗色细线白天本来就看不见。
所以白天的可见性交给**比天空亮**的东西：反照率高的平台 / 舱体 / 云气（被太阳和下方地球照亮）、镜面闪光、白天频闪。线本身不调亮。

## 返工（协调者：黄昏两张读成霓虹 / 激光，建木悬空）

- **亮度封顶**（`wonderCap`）：太阳落到地平线以下后，缆 / 枝 / 中继站 / 云气满覆盖时的亮度最多到同方向天空的 1.3 倍（贴地平线）到 2 倍（150 km 以上），按亮度等比缩、保留色相（高处金白、往下过渡到地影边的红）；光晕跟着同比缩。白天放宽到 4 倍，正午两张不变（`rework/noon-check.png` 前后对照）。
- **地影里那段接到地平线**：原来黄昏也用「背景 × 线前面空气比例」补光（那是给月光用的近似），地影里的树干 / 缆和天空一样亮，被照亮的上段像悬在半空。现在这一项只在太阳 < −12° 时生效；太阳落下后地影里的部分按「挡住身后至少 22% 的天光」画成淡剪影，一路沉进地平线的霾（中继站是暗碟、稳定缆是淡斜线）。
- 萤光更稀（出现概率 0.35 → 0.2）、更弱（夜里 15 → 6 kcd，白天闪光 1.2e6 → 6e5 kcd）。

## 已知问题 / 留给之后

- **系留平台与灯群多数时候看不见**：基座在 330–410 km，正好在地平线上，默认云量下被地平线上的云挡住（物理上对）；只有地平线干净时才若隐若现。想让它更常出现，可以把召唤距离往 330 km 偏，或者在平台上加一道被灯火照亮的低雾（下一步）。
- 黄昏被阳光照到的中继站比暮色天空亮上千倍，截成一团白（和线本身一样，W01 的取舍）；想收敛可以单独降平台反照率，但正午就淡了。
- 建木白天的三道云絮有时中间留一个洞（噪声），看起来像一只「眼」，目前保留；嫌怪可以把 `nz` 的下限提高。
- 天梯的中继站 / 舱体 / 灯的布局是固定种子（每次召唤都一样）；「随机性」目前只在不规则间隔与大小上。要每次不同，可以把航程种子传进 uniform。
- 面板闪光、频闪是按真实秒走的（`uTime`），加速播放时不加速。
