## 根因（已测量坐实）

**假设被推翻**：看板写的根因「油罐鼓包按 0.2 / 0.6 m 规则网格欠采样」不成立——`uWingDebug=1`（去鼓包）和 `=4`（去环境反射）
在 night-city 上年轮纹都还在；`=8`（去自阴影）年轮纹、in-cloud 的迷彩块、route-hnd-cts 小翼的竖向分面**全部消失**。

1. **年轮纹 / 迷彩块 / 小翼分面 = 机翼自阴影的假阴影**。临时调试位把「软阴影最小值来自哪个部件」染色后，整片上翼面的
   遮挡者都是襟翼滑轨整流罩（部件 5）。`sdWingFairing` 的包围只按展向 `|z − zf| − 0.2` 返回距离，翼面上方几米高的点
   距离场也只报几十厘米；软阴影估计 `14·d / ts` 随 ts 增大掉到 1 以下，整片上翼面被压暗到 0.2–0.5，
   而且步进采样离散，明暗成一圈圈等高线（夜里月光、正午阳光都中招）。独木舟的椭圆距离在远处按短轴缩放也严重低估。
   修法：包围加上竖直方向 `P.y − (hy + 0.35)`，两者取大，并对最终距离再取 `max(…, bound)` 兜底。
2. **前缘 1 像素硬台阶**（noon / in-cloud 都有，穿云时最显眼）：外轮廓附近的中心射线被判为「边缘像素」后，
   4 条子射线从命中距离的一半处出发、只有 64 步，贴着翼面掠射一步只挪一点，走不到前缘就用完 → 四条都算没打中 →
   整个像素露出背景。`uWingSteps=256` 全局加倍能修好但机翼 pass +40%。
   修法：非内轮廓（中心射线之前没擦过别的部件）的边缘像素，子射线从命中点前 16 个像素宽处出发；
   中心射线在「还在逼近」时步数用完可延长到 3 倍（开销约 +0.01–0.02 ms），已远离的不再「算打中」。
3. 小翼「镀铬」观感：自阴影假阴影的竖向分面 + 清漆 0.06 的清晰天空倒影 + 底漆 0.18 的第二层高光。

## 改了什么

- `wing.glsl.ts`：整流罩包围（根因 1）；掠射步数延长与子射线提升规则（根因 2）；鼓包网格 ±15% 值噪声扭曲、
  幅度 0.5–1 随机、按像素足迹（掠射拉长）淡出并把滤掉的斜率方差记到 `bumpVar`；`WingSurface.coatRough`；
  小翼航司色分界从弯折 62% 下移到 30–45%（沿弦向斜）、清漆 0.15、航司色底漆 0.35。
- `wing-shading.glsl.ts`：α² += 2σ²（基础层与清漆）；清漆环境反射按 coatRough；子射线出发点。
- 新调试位：64 关掉掠射延长，128 子射线一律从半路出发（对照旧做法）。

## 坑

- Windows 上 Python 以文本模式写文件会把 LF 换成 CRLF（`open(p, 'w')`）；要用 `newline=''`。
- 截图间机翼姿态会变（湍流 / 翼尖颤动），不同批次的截图不能用固定坐标裁同一处，同一批次内对照才可靠。
- 机翼 pass 的计时受别的代理占用 GPU 影响很大，只信同一页面里交替测的中位数（`--evals`）。
