## 怎么复现
- 本 worktree 起服务：`cd apps/voyage && node node_modules/vite/bin/vite.js --port 5211 --strictPort --host 127.0.0.1`。
- 离线频谱检查：`node apps/voyage/scripts/audio-check.mjs --port 5211`（没服务会自己起），结果写 `tmp/audio-check/spectra.json` 并打印表。
- 真实页面开关验证：`node apps/voyage/handoff/T11-live.mjs --port 5211 [--angle vulkan]`（默认静音、点击启用、闪电→雷声距离、M 键、背景板模式、控制台 error）。
- 按节点类型拆 CPU：`node apps/voyage/handoff/T11-prof.mjs`；首次启用的主线程长任务：`node apps/voyage/handoff/T11-longtask.mjs`（都需要 5211 上有服务）。
- 调试句柄：`__voyage.audio.debug()`（AudioContext 状态、各层目标值、主线程 update 累计耗时）。

## 合成设计
- **噪声床 = 频域合成**：每层给一张倍频程表（伪 dB SPL，全部层共用一个参考），每个 FFT 频点幅度 ∝ 10^(dB/20)/√f、随机相位，逆 FFT 得到 2^18–2^19 点（5.5–11 s）的噪声。逆 FFT 结果天然周期 → 循环无接缝；各层长度 / 起点不同。
- **左右去相关**：R = γL + √(1−γ²)N，γ = 扩散声场相干函数 sinc(2πf·0.25 m/c)。实测巡航相干度 31.5–125 Hz 0.93–0.97，500 Hz 0.51，≥1 kHz ≈0.16（估计量底噪）。
- **气流**：约 13·lg(q/q巡航) dB，高搁架 1.2 kHz 随 q 变亮；湍流时 ±2 dB 阵风（AR(1)）。窗那侧略响（声像 ±0.12）。
- **发动机**：宽带低频层 + 低压轴谐波（1–4 次，100% N1 = 46 Hz），两台发动机差 0.45% → 约 0.2 Hz 慢拍频；推力 爬升 1.0 / 巡航 0.8 / 低空平飞 0.62 / 下降慢车 0.3，τ = 3 s 缓变，30·lg(推力/0.8) dB；座位相对机翼：前方 −5 dB、上方 +2.5、后方 +1.5。
- **襟翼 / 缝翼**：中频宽带层，∝ 偏角（襟翼 80%、缝翼 20%）× √(q/q进近)。**扰流板**：低频抖振层，每 0.1 s 随机 0.55–1.45 倍。
- **颠簸**：泊松闷响（棕噪 70–110 Hz 低通，20 ms 起、0.2 s 衰减，速率 1.6·tb^1.5 /s，tb < 0.12 时没有）；机身咯吱（粘滑微脉冲激励 0.9–1.6 kHz / 2.2–3.4 kHz 板共振，速率 0.12·(tb−0.25) /s，峰值只有气流层 RMS 的 0.2–0.35 倍）。
- **穿云**：液态水（ISA 气温 > −8～−15°C）→ 雨（「沙」底噪 + 每秒 700 个 1.2–4.5 kHz 衰减正弦「嗒」，偏窗侧）；更冷 → 冰晶细沙（2–16 kHz，随机起伏）。按云密度 × √空速。
- **雷声**：延迟 = 距离 / 340 m/s；响度 12 − 16·lg(d/2) dB（参考棕噪表），两级低通 fc = 3000/(1+0.7d)（90–2000 Hz）；包络 = 若干高斯团 + 指数尾，近处（< 5 km）加 15 ms 炸裂，远处起音慢、时长随距离变长；同一时刻最多重叠 4 声；> 90 km 不打。
- **舱内**：空调出风（默认开，很轻，巡航时基本被气流盖住，低空 / 进近时听得出）；提示音（默认关，平均 25 分钟一次、至少隔 8 分钟，E5→C5 钟形两声，通用音色不仿任何厂商）。
- **输出**：主音量 = 滑块²；压缩器阈值 −3 / 比率 20 兜底（只有近雷碰到）。

## CPU（RTX 5090 机器，Chrome headless，d3d11）
- 实时播放的音频线程 + 主线程 update：约 **1.9–2.1% 的一个核**（离线渲染 60 s、每 0.25 s 停一次滚动排程：平静巡航 1.85%，全部图层 + 颠簸 + 每 10 s 近雷 2.08%；含 suspend 往返，偏保守）。
- 主线程：真实页面里每帧 `audio.update` 平均 7 µs（节流到 10 Hz，真正做事的那次约 57 µs）。
- 首次启用：合成全部缓冲约 0.7 s，分 9 段让出主线程；长任务实测（`T11-longtask.mjs`）最大 162 ms（2^19 点的气流层），其余 60–100 ms——点开声音那一下会卡几帧；之后切换开关没有这笔开销。
- 分项（`T11-prof.mjs`，30 s）：空图 0.04%，10 个循环源 0.23%，1 个压缩器 0.44%，10 个声像器 0.49%，全图（参数已稳）1.0%，全图（setTargetAtTime 缓变中）1.7%。

## 已知问题 / 下一步
- 我听不见：所有取值只按频谱统计和文献量级定，**需要用户戴耳机听一次**，重点：巡航底噪是否「低沉平稳」而不发嘶；发动机拍频是否太明显；雷声远近是否可信；雨 / 冰晶是否刺耳。
- 面板雷暴在 55–75 km，雷声要等 2.5–3.5 分钟、而且很闷（按题设 340 m/s）。若用户想「看到闪电很快听到雷」，需要导演 / 天气把雷暴摆近，或者放弃物理延迟（未做）。
- 首次启用的 160 ms 长任务：可以把频域合成挪进 Worker（未做）。
- 没做：头部位置对声场的影响、舱门 / 广播人声、起落架 / 发动机启动（本项目没有地面段）。
- 建议回归场景：无（声音不进截图）；审查时跑 `scripts/audio-check.mjs` 对照上表即可。
