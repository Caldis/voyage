## 第三轮返工（窗板效果、整流罩）
- 机翼像素上保留窗板效果：场景输出的 alpha 打包「窗外遮罩 m + 与窗外颜色无关的部分 A = 结果 − m·k·O」（scene.ts 的 packWingRef），
  机翼 pass 按 (1 − a)·场景 + a·(A + m·k·机翼) 合成；k（油污、水珠、透气孔的乘性系数）两边同公式。划痕、水痕、舱内反射都叠在机翼上，窗框交界的天空细线消失。
  - 放弃 MRT：ANGLE D3D 链接时只按单目标生成像素着色器，画进两张目标时首帧同步重编场景（实测首帧 50 s，有时丢上下文）。
  - 存 A 而不是 O：O 是亮的天空，6 位量化误差换到暗机翼上是满屏彩色噪点；A 在窗内很小，误差可忽略。
  - 半精度 HDR 时不打包，退回直接替换。
- 整流罩：尾段收细到 20–30%、下缘上翘成刀背、尾端小圆角；襟翼不算自阴影（去掉穿云时的硬边暗斑）；吊挂圆角、前端斜降、后段收低。

改成（`if (inBezel > 0.0 && isMain > 0.5) {` 这一行保留，后面的 `view += wingLights(...)` 与收尾的 `}` 不动）：
```glsl

  // 机翼（wing-shading.glsl.ts）：a 是覆盖率，< 1 的是轮廓上的像素（边缘已在里面超采样），要和窗外按覆盖率混合

  view = vec3(0.0);
  if (wing.a < 1.0) {
    vec3 rdW = uCabinToWorld * rd;
    view = outsideRadiance(rdW, cloud);

```
