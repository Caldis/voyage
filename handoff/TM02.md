## 方案

TM01 的全局增益 `G(l)` 在中灰 +2.5 档以上必须收回（白点不能动），收回段把最亮一段的细节一起压扁——TM01 的 480 组扫描证明同一条全局曲线下「云芯 ×1.6」与「215–235 段 ≥ ×0.95」不可兼得。改成 base / detail 分解（Durand 2002 的廉价版）：

```
d  = log2 Y(眩光 × 曝光) − l                    // 低通相对像素（档）
d' = d / (1 + (d/σr)²) · 开关 · clamp((R − m)/top, 0, 1)   // 值域回落 + 白点前退回全局
b  = l + d'（最大通道同样 + d'，饱和度前移照旧）
增益 = max(G(b) + (S(b) − 1)·(l − b), 0)
S − 1 = (sd − 1)·max(H'(b), 0) + κ·G(b)
```

- 中间段：sd = s 时 `G(b) + G'(b)(l − b) ≈ G(l)`（一阶泰勒），就是 TM01；sd 取 1.4 > s 1.3：细节（云芯纹理）按 1.4，大尺度（云体亮度、银边的 rim）仍按 1.3，不再整体变亮。
- 收回段：G' < 0 截到 0，细节不跟着收回；κ·G 补「增益把像素推到 AgX 更平的肩部」的斜率损失（离线复刻 AgX：κ 0.4 时 215–230 段 ×0.99，`scratchpad/tm02_design.py`，没进仓库）。
- 定稿 `uDayHiLocal = (1.4, 0.4, 0.5, 1)`、`uDayHiLocalTop = 1.0`；`uDayHiLocal.w = 0` 逐位回到 TM01（A/B 里的 master 变体就是这样拍的）。门控（白天 × 非云中 × 窗外 × 云不透明度）完全沿用 TM01。

## 光晕控制

局部色调映射的经典伪影是亮边外一圈暗晕 / 暗边内一圈亮晕。三道：
1. **值域回落**（双边 / 引导滤波的廉价近似）：只把 |d| ≲ σr 的起伏当细节；跨云边、太阳光晕的大落差 d' → 0，退回全局曲线；局部项最多偏 (S − 1)·σr/2。
2. **中间段与全局一致**（上面的泰勒关系），局部项主要只在收回段起作用。
3. **结果截到 ≥ 0**：不比 AgX 原样更暗，云边暗侧不会被压出暗晕；天空由云不透明度门控，逐位为 0。

**光晕指标**（`TM02-halo.py`）：D = 变体 − 参考（master）的显示 luma；在离云边 ≥ 25 px 的云内部按参考亮度（每 1 级）取 D 的中位数 f(L)——这就是「逐点曲线会给的改变量」；残差 R = D − f(L_ref)。按离云边的距离（不透明度 0.5 等值线，4 邻域）分格报 R 均值；**光晕幅度** = 近边各格与内部格之差的最大值（显示级），**宽度** = 差 > 0.5 级的最远格外沿。只算窗内（`uDebugMask` 截图腐蚀 4 px）。逐点曲线（g14）的残差恒 ≈ 0（≤ 0.1，backlit 0.3），可作对照；两次同代码累积（master2）为 0.00。

## 还不够好 / 给协调者与美术总监

1. **观感上是细微的改动**：与 master 逐像素最大差只有 2–3 级，窗均值 +0.1。它解决的是「最亮一段细节被压」与「云芯对比只能到 1.3」这对矛盾，不会让画面一眼变样；用户说的「锐利、边缘高光的高分辨率质感」主要还得靠云本身（C03 / C09 / C10、分辨率与重建），色调映射这边的余量基本用完了。
2. 最亮段只回到 ×0.95–0.97、不是 ×1.0：眩光低通最细一级（约 2 px）占 45% 权重，2–8 px 尺度的结构一半仍按曲线收回（README 坑三）。要再多，得给曝光合成一个更宽的低通（多采 4 次 uBloom 或读 bloom 的某一级 down 纹理，后者要改 bloom.ts 接口并多一个 sampler），我没做。
3. sd 再大（1.5）云芯对比还能涨，但 storm-day 砧边光晕到 1.6 级以上，按「宁可小，不要糊」没取。
