## 改了什么
1. 测光目标 1×1 → 2×1：左像素亮度（不变），右像素色度（舱内按面积 / 窗外中心加权，各通道对数均值，16×16 采样，按上一帧适应亮度排除高光和近黑样本）。
2. 适应：色度与亮度同速（舱内色度跟舱内亮度的明 / 暗适应速度，窗外跟窗外）。
3. 最终合成，只作用于舱内像素（按遮罩 alpha 过渡，窗外 a = 1 的像素一字节不变）：
   - 舱内光源色 = 舱内平均色 ÷ `uCabinRefAlbedo` (0.75, 0.72, 0.665)；适应白点 = 窗外平均色与舱内光源色的对数混合，舱内权重 k = mix(0.7, 1, dom)。
   - CAT02 LMS 部分 von Kries，D = mix(0.65, 0.72, dom)；之后按原亮度归一，只改色度。
   - dom = smoothstep(−1, 2, c − o)（舱内比窗外亮多少档）。
4. 「舱灯开 + 窗外暗 → 舱内是主导适应区」：lit = dom · smoothstep(0.5, 1.2, log10 舱内 cd/m²)（睡眠 / 全关 ≈ 0），lit 时 β → 1、明度恒常 +0.35 EV、T23 的③（舱内不许比窗外亮）放开到④。窗外曝光不动。
5. 公式全文见 exposure.ts `Exposure` 类上方注释。所有参数都是 uniform，可在控制台调：`__voyage.exposure.finalMat.uniforms.uChromaD.value.set(0,0)` 关掉色适应（关掉后舱内与改前逐像素一致，已验证）。
