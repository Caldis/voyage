### 结论

**压平发生在受光计算，不在色调映射。** 具体：
1. **多次散射占了受光面 80% 以上的亮度，而它随受光光学厚度 od 变化得太慢**：第 2 阶 `0.25·p·e^(−0.25·od)` 在 od 0.5 → 2.5 只降到 0.61，×6 标定后是受光面的主体。
   对照物理（Chandrasekhar 半无限保守散射层的反射，I ∝ μ0·H(μ0)·H(μ)/(μ + μ0)，H(1) ≈ 2.91、H(0.5) ≈ 1.98、H(0.2) ≈ 1.45、H(0.1) ≈ 1.25）：可见样本的受光 od ≈ τv·μ/μ0（τv ≈ 1），
   μ = 0.5 时 od 0.5 / 1 / 2.5 / 5 应对应 1 / 0.52 / 0.21 / 0.11（近似 0.5/od，即朗伯的余弦律）；现行曲线是 1 / 0.80 / 0.43 / 0.17——**在 od 1–3（侧光、掠射的受光面）亮了约 2 倍**，明暗交界线被抹平。
2. **粉末项压暗的正是最亮的受光面**：`powder = 1 − e^(−2·od − 0.5)` 按受光 od 算，od 小（正对太阳的面）最暗，顺光 / 侧光时乘 0.5 的强度——等于在受光面上反着朗伯走。去掉后受光面 p90 ×1.14–1.22、受光 / 背光 +8~12%。物理上「多次散射还没攒起来」取决于视线方向上的厚度（薄边），不是受光 od。
3. 环境光（1–5%，云缝 ≤ 24%）和扩散尾巴（1–16%）都不是主因：去掉环境光受光 / 背光只 +1~15%，去掉尾巴 +4~20%。
4. 色调映射不是主因：见上表。TM02 记录里「TM 余量已用完」的结论在这里也成立，不需要动 exposure.ts。
5. 真实积云的对照：受光面 / 背光面在侧光时约 4–8 倍、顺光时约 2–4 倍 **[估算]**（受光面 πL/E ≈ 0.8·余弦律，背光面靠天空光（3–5 km 高度晴空散射约占总照度 8–12%）+ 邻云反射 + 漫透射，πL/E ≈ 0.1–0.2；WMO《国际云图》描述侧光积云「明暗对比强烈」、对日一侧「亮度差异非常显著」，https://cloudatlas.wmo.int/en/explanatory-remarks-and-special-clouds-cumulus.html ）。
   我们的顺光 / 正午场景受光 / 背光 1.75–2.7，偏低；低太阳 / 逆光（19–24）已经足够。
6. 另：`od` 读回（S 换成 od 的变体）按 cur 分类的中位：noon-cu-close 受光 0.97 / 背光 3.0 / 云缝 4.8；noon-cumulus 1.6 / 6.7 / 8.4。od 本身有 3–4 倍的差，是**响应曲线**把它压扁了。
