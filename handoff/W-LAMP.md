## 已做（src/render/wing-shading.glsl.ts、wing.glsl.ts 一行导出曲率）

1. `wingLampSurfI`：照翼面专用的配光（灯本身的亮点、云雾光晕仍用 `wingLampIntensity`，逐位不变）。FAR 25.1393 / 25.1401 竖直分布（平滑近似，高仰角底 0.15 / 0.2 为估计值）、水平台阶放软、近竖直方向按水平平均——修掉「dir.xz 零头来回翻 20 cd / 2 cd」造成的小翼内侧硬边亮块、灯下亮带。
2. 距离：`max(d², 0.04)` 平台 → 圆盘光源 `I / (d² + R²)`，R = 5 cm。
3. 地平线：`n·l` 硬截断 → 面光源地平线 `(n·l + sinα)² / (4 sinα)`，sinα 取光源张角与像素内法线转角一半的较大者（`gWingCurv` 由 wingTrace 的拉普拉斯曲率导出）。
   根因（实测，`tmp/screenshot/wlamp/enc3`）：翼尖后缘一线的暗点是尾灯几乎和翼面共面，n·l 在 0 附近按距离场法线 ±0.005 的噪声来回过零、再乘 1/d²——和边缘超采样、去亮点限幅无关（`uWingEdgeAA = 0` 照样有）。
4. 去亮点：灯光一份单独限幅（中位样本 × 2），太阳 / 天空一份仍按旧规则。
5. 灯的镜面粗糙度不跟边缘判定走，α² 加像素内法线转角²。
