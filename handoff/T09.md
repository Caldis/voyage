原图用 4k（4096×2048，每像素 5.3′）：和现有星图同尺寸，直接装进星图的 A 通道。8k 原图也下过，要单独再占一张纹理（窗外程序 sampler 已满 16/16）且 GPU 占 256 MB，不值得。
**为什么 5.3′ 够**：银河亮度在 1e-4 cd/m² 量级，那时是暗视觉，人眼的分辨率只有 10–20′，比这张图还粗；窗里放大约 2 倍、双线性过滤，看不到马赛克（截图放大拉伸检查过，见下）。

资源文件 `public/data/milkyway_4k.jpg`：8 位灰度、对数编码（code 1..255 ↔ log10 亮度 −3.5..0，0 = 更暗），**JPEG 质量 90，3.3 MB**。无损 PNG 要 6.2 MB（暗星噪声压不下去），WebP 无损 6.0 MB；JPEG 在对数域的误差 ±2 级 ≈ ±3%，叠在本来就有星点噪声的纹理上看不出来，解码时再加半级确定性抖动防等高线。没用 KTX2：现有加载链路没有 KTX2 解码器，且数据要在 CPU 上和点星拼进同一张半精度纹理。
生成：`uv run --python 3.12 --with numpy --with pillow --with openexr python apps/voyage/scripts/build_milkyway.py`（原图 35 MB 缓存在 `tmp/milkyway/`）。

## 2. 做了什么

- `src/sky-assets.ts`：`buildStarMap()` 并行加载银河 JPEG，解码成相对亮度放进星图的 **A 通道**（原来恒为 1、没人读）。不加 sampler、不加纹理采样次数（和点星共用一次 `texture()`）。加载失败时 A = 0，其它照常。
- `src/render/stars.glsl.ts`：`starRadiance(rd, tUp, background)`
  - **物理定标（估算）**：人马座大星云（l=2°, b=−4°）取 V ≈ 20.7 等/角秒² ≈ 5.7e-4 cd/m²（Roach & Gordon 的 S10 量级给约 20.3，Masana 2021 GAMBONS 表 3 的 l=45° 值按图上比值外推给约 21.1，取中间）。对照夜天光 22 等/角秒²：最亮的银河约是无月夜空底色的 3.5 倍，银极附近远低于底色。颜色取亮区平均色（偏暖），暗视觉下由浦肯野压灰。
  - **大气消光**：和点星一样乘 `tUp`（相机上方的透射率）。
  - **眼睛的对比度阈值**：Blackwell 大目标阈值的近似拟合 Cth ≈ 0.04·(B/3.4e-3 cd/m²)^−0.44（估算），显示量 × max(1 − Cth/C, 0)。背景 B = 画出来的天空（含月光照亮的天空、夜天光）+ 城市人工天光 `uSkyGlow` + 舱内光在眼里的光幕（Holladay，舱灯 200 lux、氛围灯估 0.3 lux、全关按 0）。
  - **对比度转移**：城市天光和光幕没画进天空，所以银河再乘「画出来的底色 ÷ 真实底色」（不乘的话城市上空几乎不变淡，见 README 坑点）。
- `src/render/outside-pass.ts`（天空合成一行）：`L += moonDisk(rd) * tUp + starRadiance(rd, tUp, L);`——此时的 `L` 就是天空底色。
- `src/light-pollution.ts`（新模块）：从地面 clipmap 已下好的 Black Marble 夜光（水体纹理 B 通道，只读）在 150 km 内按 Walker 定律（d^−2.5）加权，得城市灯光强度 S；人工天光 = 自然夜天光 × 60 × S × 「飞机高度以上的散射比例」（分子 8 km、气溶胶 1.5 km 标高各半，巡航约 13%、4 km 约 34%）。系数都是**估算**，只影响银河变淡多少。2 秒重算一次。没开真实地理时为 0。
- 场景：`scenarios.mjs` / `regression.playwright.js` 加 `night-sea-milkyway`（南海 scs、左座朝东南、2026-05-15 22:30、全关舱灯、残月在地平线下 53°，人马座大星云高 11° 在窗正中；用 astronomy-engine 扫全年挑的）。`applyScene` 支持 `date`：日期框只响应 `change`；没写 `date` 的场景恢复成页面打开时的日期（已有场景行为不变）。
- `scripts/build_milkyway.py`、README（模块表、物理近似表、数据来源与许可、坑点 4 条）。

## 5. 已知问题 / 没做的

1. **6.5–11.5 等之间的星两边都没有**（BSC5 到 6.5 等，SVS 银河图从约 11.5 等起）。这段星单颗肉眼看不见；它们的积分光在银河带里是少数，在高银纬约占积分星光的一半，但那里本来就低于夜天光，画面上看不出。要补可以把 `hiptyc_2020` 挖掉 BSC 星后大半径模糊成漫射光，暂不值得。
2. **城市天光只进银河的可见度，没画进天空**（天空不出现城市光穹），点星也不随城市变暗。要做「城市上空星星变少、地平线有橙色光穹」应另开任务（会改 night-city 观感，需美术总监看）。
3. 定标、阈值拟合、光污染系数、氛围灯 0.3 lux 都是**估算**（代码里写了来源与推算）；审美上若嫌银河太淡 / 太亮，优先调 `MILKY_WAY_UNIT`（20.3–21.1 等/角秒² 之间都说得通）。
4. **观察到的既有问题（不是 T09 引入的）**：所有夜景窗里同一屏幕位置有一对「亮星」（night-sea-milkyway 在 (920,355)、night-city 在 (680,340)，头位变了它在窗里出现两次），天空怎么换它都在，应是舱内某光源在窗板上的倒影或交通机灯，建议美术总监 / T35 看一眼。night-city 的星星是短划线（运动模糊或曝光时间），也是原有的。
