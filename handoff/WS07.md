## 做了什么

| 部件 | 现在 | 与简报的差别及理由 |
| --- | --- | --- |
| 根数 / 尺寸 | 5–12 根（按种子），柱顶 30–70 km，柱径 2.6–7.2 km；最近三根里有一根「主柱」56–70 km 高、半径 2.9–3.6 km | 简报柱径 2–6 km：主柱放到 7.2 km，窗里主体块才有 50–60 px 宽（M2 > 11%）；柱顶上限 60 → 70 km 让主柱在默认头位出画（M7） |
| 截面 | 六成的群是**同一朝向的方柱**（方尖碑阵变体），四成是圆柱 | 第一版全是圆柱 + 等距外凸环带 + 外张柱头，截图读成烟囱 / 水管（README 坑点）；方柱在前棱处受光面 / 背光面一刀分开，读成一整块混凝土 |
| 摆放 | 沿一条与视线夹 15°–45° 的斜线往地平线退，间距 14–40 km 不规则（四分之一挨得很近）、五分之一偏离行 10–22 km；最近一根在锚点前 60–85 km，最远的柱脚沉到地平线以下只剩柱顶；锚点 180–280 km | 简报 150–300 km：最近一根实际在 110–230 km |
| 尺度线索（三级细节） | 轮廓（50–100 px 宽、500+ px 高）→ 环带（每 7–14 km、三成缺着）/ 三分之一的柱子在 45–70% 高处退一级台 / 柱顶风化暗带 → 竖肋、1.8 km 施工缝、雨痕、3–5 km 一块的面板色差（都按像素足迹积分 / 淡出） | 施工缝和肋收弱（太强是一张方格纸，尺度反而变小） |
| 云交互 | 近处真实云海挡住柱脚；柱子挡住比它远的真实云（`gWonderCov / gWonderT`，只按实体）；每根柱脚一圈顺风拖出去的云墙；约三分之一的柱子在 8–13 km（和我们一样高）挂旗云；一架同高度航班的航迹云（10.3–11.8 km）横穿柱群，在一些柱子前面、一些后面 | 云涡没做成旋涡形，是被柱子搅起、顺风拖长的一截云墙 |
| 大气分层 | 物理空气透视（不另加）：柱脚埋在霾里、柱顶在稀薄高空清楚；远柱更淡 | — |
| 黄昏 | 真实地影：柱脚已入夜、柱顶按各自高度被染成粉红（`ws-pillars-dusk` 17:48，一眼看出哪根更高） | — |
| 夜 | 近乎剪影（月光下受光面淡淡可见），柱顶两角 + 前棱 / 正中红灯全部同步慢闪，每道环带上沿朝相机一圈暖白灯（0.7 km 一盏、三分之一空着，描出方 / 圆与分段）；柱子挡住身后的点星 | — |
| 浮现 | 同天梯：可见前沿从地平线的霾里往上长（120 s） | — |
| 随机性 | 根数、截面、朝向、每根的高 / 粗 / 位置 / 退台 / 环带节距与缺失 / 色差、旗云有无与高度、风向、航迹云航向 / 高度 / 相位全按种子 | — |

没做：**柱体投在云海上的长影**（可选项）——150–250 km 外柱脚一带的云海在窗里被压成地平线上几个像素高的一条，影子看不出来；做的话要在云缓冲上按云深度逐柱判影（OWP 里可做，成本不大），建议等用户看图后再定。

## 真实感对照（四条铁律）

- 宁可小不要糊：轮廓、退台、环带、前棱都是像面解析覆盖率，远处细纹按足迹淡出，`ab live` 零闪烁。
- 宁可有雾：柱脚埋在物理空气透视与云海里，不露低清。
- 随机性：几十个参数按种子，每次出现方 / 圆、根数、疏密、旗云都不同。
- 尺度：航迹云（同高度的一架飞机）只到柱子脚踝；黄昏只剩柱顶被照亮，高低一眼可比。
