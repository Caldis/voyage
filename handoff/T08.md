# T08 · 道路灯带 · 交接

分支 `worktree-agent-af3497178b421a07c`（基于 master `f98b307`）。**不需要协调者往 main.ts / scene.ts 接入任何代码**：没有新 uniform、没有新 sampler（窗外程序仍 14/16），数据走现有两张纹理的 A 通道。

## 做了什么

- **数据**：OpenFreeMap 矢量瓦片的 `transportation` 图层（和水体同一张瓦片、同一次请求，不新增外部服务，不走 Overpass）。
  收 motorway / trunk（高速、快速路）和 primary / secondary / tertiary / minor；隧道、施工中、轮渡、铁路、步道不收。
  等级 → 照亮宽度与强度是经验取值（`tiles.ts` 的 `ROAD_CLASS`，注释里写明「不是实测」）。
- **亮不亮**：数据里没有「有没有路灯」，不编——由 NASA Black Marble 夜光决定：普通道路只在有夜光处亮；高速 / 快速路在城外也留约 2 成（立交、收费站、车灯），
  所以城市之间是一条连续的淡线、进城变亮（`road-raster.ts` 的 `ROAD_LIT_*`）。没有矢量数据的地方没有线。
- **栅格化**（`src/ground/road-raster.ts`，新建）：每级 clipmap 把道路栅格成「到最近中心线的有向距离」（水体纹理 A）+「照亮宽度」（影像纹理 A 的高半段，
  低半段保留缺瓦片语义）。投影、抽稀、求距离、和夜光 / 影像合成全在 Web Worker（`road-raster.worker.ts`，新建）里，像素缓冲区转移往返。
- **着色**（`ground.glsl.ts` 的 `groundRoadCoverage`、`terrain-shading.glsl.ts` 的 `groundRoadLights`，只在 `groundFinish` 调用一次）：
  有向距离双线性还原线位 → 按像素足迹做解析盒式抗锯齿；沿视线方向的长轴取 1–6 个点（各向异性过滤）；中心处梯度判假线；
  级别按横向足迹选、在级别边缘渐变到粗一级。沿线亮度三个尺度（170 m / 650 m / 2.9 km）的起伏、钠灯橙 / LED 白按 4 km 片区混合、
  近处（足迹长轴 < 约 20 m）一盏盏路灯的光斑（按足迹椭圆展宽）、黄昏按片区在太阳高度 0°–3° 之间先后开灯。道路不乘水体遮罩（桥上也亮）。
- **顺手修**：矢量瓦片里贴着缓冲区边走的线段（沿经 / 纬线的笔直假线），道路和河道都去掉了。
- **场景**：新增 `route-hnd-cts-night`（hnd-cts，21:30，左座看关东平原，云量 0.1，舱灯睡眠），`scenarios.mjs` 与 `regression.playwright.js` 同步（`check:glsl` 的同步检查通过）。
- **调试**：`uDebug = 24` 只画道路灯带。

## 已知问题 / 留给后续

1. **城市灯点（`groundLand` 30 m 一格的光点，T08 之前就有）仍有斜看的横向短划与远处能量衰减**。T08 试过按足迹椭圆展宽 + 远处换期望值，
   城区在中距离变成过曝的平涂白斑、露出城区遮罩的形状，观感更差，已整段撤回（该段代码与 master 一致）。修它需要连同城区遮罩的软化一起做，建议单开任务。
2. 低空（night-city 4 km）近处路口密集处，有向距离在多条路交汇时仍有小的缺口 / 毛刺（中心梯度判假线会误伤一点真线）；巡航高度看不出。
3. 双向分离的高速在纹素 > 20 m 的级别按「两条线并一条、宽度 ×2」近似；个别单幅的 motorway 在远处会偏亮一点。
4. 道路亮度、等级权重、「亮不亮」阈值都是按截图调的经验值（注释已标）。没有和真实夜景照片逐项对过亮度比例，美术总监可以再看一次城区里道路与灯点的比例。
5. 更远的级别（z8–z9 矢量瓦片）只剩高速和主干道，近处级别才有支路：支路随距离渐隐是数据本身的层级，不是 bug。

## 开发体验反馈

- **哪里慢**：视觉迭代每轮约 1–2 分钟（vulkan 下 `dev-browser shots` 两个场景 + 等瓦片），总共十来轮，可以接受。d3d11 冷编译每次 15–25 s，只在最后测。
  最耗时的是「判断是不是闪」：没有现成的时间稳定性测量，自己写了亚像素步进连拍（停掉主循环、`benchFrame(2)` 手动推进）+ 块能量统计，这个方法很好用，建议收进 `dev-browser.mjs`（比如 `flicker` 子命令）。
- **哪里卡**：
  - `dev-browser.mjs shots --out` 是相对仓库根解析的，我写了 `../../tmp/...` 结果写到了仓库外面；文档里写清「相对仓库根」会省事。
  - `dev-browser.mjs shots` 不抓控制台 error，也不关频闪（频闪偶尔在截图里是一大团白光，差点当成回归）；T34 的脚本里有 `wingDebug.strobe = 0`，建议 shots 默认关频闪并打印 error。
  - Bash 工具在 worktree 隔离下拒绝 `for f in ...; sed $f`、`cd $(…)` 这类「运行时计算参数」的命令，多次要拆成单条或改用 Edit / Python 脚本。
  - 主循环没有「暂停飞行」的调试开关，测闪烁时只能把 `requestAnimationFrame` 换成空函数再手动 `benchFrame`；一个 `__voyage.freezeFlight` 之类的开关会更直接。
- **怎么绕过的**：见上；截图局部放大 / 差异 / 过曝统计的小脚本都留在 `handoff/T08-*.py`。
