## 几何推导与检查结果

- 车轴（3 辆编组坐中间，示例）：本车 ±5.85、±7.95 m；相邻车 ±12.05、±14.15、±25.85、±27.95 m。响度按到耳朵的距离（耳朵高于轨面 2.4 m，估）20·lg，别的车厢再 −6 dB（估）。
- `rhythmTable(90)`：周期 **1.000 s**；本车「タタン」在 0.234 / 0.318 s 和 0.682 / 0.766 s，相邻车 0.434–0.566 s，远端 0.034 / 0.118 / 0.882 / 0.966 s——和 TRAIN.md §6.1 的推导逐项一致。
- 渲染后实测（`audio-check --rail`，只听事件，10 ms 包络自相关，带防倍周期）：90 km/h **1.000 s**、60 km/h **1.499 s**；起音时刻与排程一致（例 0.526 / 0.61、0.976 / 1.06 s）。长轨化 8 s 内 0 次撞击。
- 道口多普勒：**静止声源、运动听者 f'/f = (c + v·cosθ)/c**（TRAIN.md §6.2 用的是声源运动公式 c/(c ∓ v)，这里更正，差 0.6%）。c = 346.1 m/s（25°C，估）。90 km/h：靠近 ×1.0722、离开 ×0.9278，跌落 2.51 半音；700 Hz → 750.6 / 649.5，750 Hz → 804.2 / 695.8。
  实现上按距离变化率 1 − ṙ/c 逐 16 点写播放速率曲线（含传播延迟迭代求接收时刻）。渲染实测：通过前 744.7 Hz（理论 743.8，本机 693.7 Hz）、通过后 649.8 Hz（理论 643.6；两台警报机 693.7 / 706.2 Hz 的峰混在一起，偏高 1%）。
- 频谱（dBFS，音量 100%，`tmp/audio-check/rail.json`）：巡航 90 km/h 定尺 总 −27.8 / A −36.4 / 峰 −12.2；长轨化 −29.0 / −36.5 / −15.4；60 km/h −32.8；停车后只剩空调 −48.1；道口通过 ±1 s 警报单独 −41.7（峰 −24.4，1 kHz 带与底噪相当）；广播喃喃声 −28.8（250–500 Hz 高出底噪）；真实线路 0.4 km 起 40 s（真实速度曲线）峰 −10、削波 0。
- 变频器（示意）换挡：25 km/h 异步 1000 Hz → 27 脉冲 843 Hz；35 km/h → 15 脉冲 658 Hz；50 km/h → 9 脉冲 562 Hz；齿轮音 60 km/h 636 Hz。
- 真实页面（`TR07-live.mjs`）：切火车后声场换成火车、「次は 柏矢町」字幕出现；接缝下拉生效；终点前「まもなく 終点 信濃大町」；M 键挂起；切回飞机恢复；控制台 0 error。

## 各声源参数与出处（详见代码注释）

- 有出处：定尺 25 m（民鉄協）；台车中心距 13.8 m（E231 系，借用，估）；车长 20 m（E233 系）；警报 700 / 750 Hz、每分钟 130 次（Wikipedia 踏切警報機原文「発振周波数の750 Hzと700 Hzの電気信号を変調周波数により1分間に130回断続」，TR07 查阅）；营运最高 95 km/h（烘焙报告，二手）。
- **未核实 / 示例**：本线是否仍是定尺钢轨（默认「定尺」是为了听到 TRAIN.md 第一期要求的ガタンゴトン，面板标示例）；接缝相对式还是相互式（取相对式 + 0.05–0.35 m 随机错开）；编组 3 辆；两个警报音交替还是同时（原文没说，取同时，`BELL_ALTERNATE` 可切）；警报提前量（同条目写「40～50秒程前」，语境未核实，取 40 s）。
- 估：轴距 2.1 m、滚动噪声 30·lg(v)（Thompson，按记忆引用）、车体隔声 −27 dB、警报机位置 / 台数、道岔位置（从股道数变化推断）、伸缩接头 1200 m、尖啸半径 260–330 m 且 55% 的弯道会叫、齿轮比 6.06 / 轮径 0.86 m / 17 齿、所有频谱表。
- 广播：随机元音共振峰合成的喃喃声，不录制 / 不采样 / 不模仿真实广播；字幕用 TR01 站名。

## 主线程开销（`TR07-prof.mjs`，火车模式、声音开，10 s）

- `CabinAudio.update` 每帧平均 **22 µs**、最大 0.6 ms；其中 `RailSoundscape.update`（10 Hz）平均 205 µs / 次（道口循环 + 接缝排程 + 参数设置）。
- 广播喃喃声第一版在广播那一刻现算，是一次 **63.5 ms** 的长任务；已改成建图时预合成 3 段 7 s（逐段让出）。建火车声音图（第一次在火车模式下出声时）有一次约 2^19 点噪声合成的长任务，和 T11 的飞机同量级（约 150 ms，未单独测）。
- 音频线程 CPU 没测（不开浏览器做性能测量）；声源数：常驻约 9 个循环 / 振荡器，事件 90 km/h 定尺时约 24 次撞击 / 秒（每次 1 源 + 1 增益，约 0.4 s）。

5. 雷声在火车模式下仍走飞机的雷声（按客机机舱的低通），没有为车厢单独调。
