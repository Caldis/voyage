## 画面（全部在 `src/wonders/floatcity.glsl.ts`，前缀 `flc`）

| 部件 | 做法 | 看点 |
| --- | --- | --- |
| 巨树树冠 | SDF：半球形大椭球 + 7 个绕一圈的团块 + 顶上 1 个，平滑并集，一次纹理两级 Worley 鼓成菜花团（按足迹选 mip）；墨绿反照率约 0.07；树冠外沿 0–0.2 km 一层稀疏「叶雾」介质（用同一个树冠 SDF 定位） | 远看是一团墨绿的「绿云」，比周围的云暗且偏绿；逆光时叶雾被照透成一圈亮边 |
| 台地 | 4 层收窄的圆台（按种子偏心），墙头按方位约三成塌掉一截；外墙拱廊的暗带（足迹大于拱距时取平均，不闪）、顶面长满植被；4 座残塔斜着断顶 | 顺光 / 黄昏时是一圈圈浅色的阶梯 |
| 岩石底座 | 倒扣的椭球半球（上沿按方位分 9 段崩塌面）+ 正中往下突出的岩锥；水平层理（按足迹淡掉）；缠根的 7 条螺旋棱鼓在底座和外墙上 | 倒扣的「陀螺」剪影 |
| 垂根 | 7 条从底座下面垂下来的粗根（SDF，越往下越细、轻微摆动）+ 细根须的「帘子」介质（纹理与 y 无关的一根根细柱，长短不齐） | 城下垂着的根须 |
| 瀑布 | 1–2 道（约三分之一的出现只有一道），从岩石上沿落下：抛出去一点、顺风吹偏、越落越宽，截面按水量守恒变稀、一路蒸发，0.6–2.5 km 处散成一团雾；最小宽度按像素足迹展宽（能量守恒）；水团纹理往下流 | 细白的一道，落到一半化雾 |
| 雾 | 整个雾罩里极薄一层（`pr²` 平滑到边缘，免得成圆盘）+ 底座下挂着的一团云（成团，不是雾墙） | 逆光时底座下的云团被照亮 |
| 光束 | 雾的受光自己算：主光源 × 城的遮挡（底座 + 台地实心椭球；树冠椭球里有投在「垂直于光线的平面」上的缝隙图案，沿光线不变）× 雾自己的影子（弦长近似、三阶多次散射）+ 天光 + 云海反光 | 近处 / 浮现时明显；80 km 外只有十来像素（见「已知问题」） |
| 云海上的影子 | W00 投影椭球（`caster` 中心 (0, 0.5, 0)、半轴 3 km） | 下方云海上一块影子 |
| 夜里的微光 | 岩锥尖一点极淡的青色点光（致敬「飞行石」），约 4e-6 kcd/m²、软封顶，60 s 呼吸 | 只在夜里、且几乎看不出 |
| 浮现 / 退场 | reveal 0 → 0.1：一团「形状不太对劲的云」从中心长出来（包住整座城的球 + 低频歪斜 + 外沿成团）；0.12 起城的表面才加进来（此时已被云完全裹住）；0.2 → 0.7 云散开；退场反过来 | `tmp/screenshot/W03/final/zrise.png` |

**随机**（`uWonderParams.z` 种子）：整座城绕竖轴的朝向、台地偏心、墙头塌的段、残塔位置 / 高度 / 断口、树冠团块、底座上沿的崩塌段、缠根与垂根的位置和长度、瀑布方位 / 条数 / 风向、雾的纹理都随种子变。

**时段取舍**：自动出现只在白天到黄昏（`sunWeight`：太阳 5–25° 权重 3、−5..5° 为 2、更高 1.5、< −5° 为 0）。夜里手动召唤也能看：月光下的剪影 + 底座下云团的一点月光 + 几乎看不出的微光（2026-09-27 近满月，所以 `floatcity-night` 截图里石头还看得出；无月夜就只剩剪影）。
**亮度**：只有受光物体（反照率 5–26%，雾 / 瀑布 0.92–0.96，与云同一套光照与相函数），不会比同条件下的云更亮，所以没有另外做「按同方向天空封顶」；目视各场景都没有截白。唯一的自发光（微光）软封顶在 1e-5 kcd/m²。

## 已知问题 / 留给之后

- **光束在 80 km 外很弱**：物理上城自己的体积阴影在屏幕上只有十来像素（README 坑点）。逆光的读法靠剪影、树冠亮边、底座下被照亮的云团。画面级「云隙光」需要云系统（T12 / clouds/*）在相机与奇观之间的云里做——**需求**：云步进变体里对奇观的投影椭球 / 树冠缝隙做一次和现在 caster 一样的区间判断，给云的内散射也挡光（现在 caster 只挡直射到云上的光，已经能在云里出影子柱，缺的是缝隙图案）。
- 云海上的影子是一个椭球的影子（W00 接口），远看边缘比较硬、像一个坑；要更像城的形状，需要 caster 支持多个椭球（树冠 + 底座）。
- 树冠逆光时的叶雾亮斑有点成块（噪声阈值），80 km 外不明显，近看（< 45 km）像零散的亮团。
- 浮现的「云」是一团独立的积云状云，和周围云的种类（层积云 / 高积云）不一定搭；外形歪斜但仍偏圆。
- 「龙之巢」（环形积雨云风眼里出现）没做：需要云系统配合。
- 没有「认得出」测试（需要另起一个没看过设计的代理看 `wonder-floatcity-day.png` / 64 px 剪影）——建议审查代理做。
- 白天手动召唤时浮现照常走 90 s；截图 / 回归直接 reveal = 1。
