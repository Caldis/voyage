## 改了什么

1. **白天窗外高光段（方案 ③）**：曝光合成里、AgX 之前，`dayHighlightGain(x)`：
   - 按亮度（相对中灰 0.18 的档）在 +0.5 → +2.5 之间把对数斜率 ×1.4（局部对比 ×1.4）；
   - +2.5 以上**按最大通道**收回，到 +4.0 档时增益归零（白点附近不再往上推）；增益 ≥ 0，只乘标量、不改色度；
   - 软铰链（±0.5 档二次过渡），亮度低于中灰 +0 档的像素逐位不变（海、天空、地面大部分）；
   - 门控 `hiGate = day × (1 − 均匀视野) × 窗外遮罩`：夜里、黄昏（day = 0）、舱内、云里 / 雪原（⑤ 已把它抬成白）都是 0。交界像素按 alpha，增益单调，只会落在两侧之间（T47 的「不过冲」不受影响）。
   - 参数 `uDayHiLook = (0.5, 2.5, 4.0, 1.4)`：膝点、顶点、收回终点、段内斜率；`w = 1` 即关。
2. **C02 锚定的软拐角**：`eO += mix(max(g,0), 0.5·clamp(g+0.5,0,1)² + max(g−0.5,0), uDayEvSoft)·day·y`，g = 锚点 − eO。离锚点 ±0.5 档以外与 C02 逐位相同，锚点处多抬 0.125 档，C1 连续（云飘进飘出时曝光的变化率不再突变）。`uDayEvSoft = 0` 即 C02。
   - 没做「锚点以上仍保留一部分自适应」（C01 审查的建议）：它经 ③ ④ 把舱壁一起压暗（保留 30% 时 clouds-variety 舱壁 148 → 140、cu-side 150 → 142），违反「舱内不变」。

## 性能

- 离线 FXC（`shader-budget --baseline tmp/tm01-base --rounds 9–11`，判定按最小值）：**exposure-final +1.2% / +2.4%**（两次，83 vs 82、86 vs 84 ms）；exposure-adapt 在噪声内（`--variants` 同批里定稿 = 撤回 = 45 ms；对照 master 的两次 +4.7% / +8.9%，44–49 ms，MAD 高达 120+）；scene-default −3.0% / +4.4%（8–9 s，噪声）。
  - 踩到：软拐角写成 `max(g,0) + 0.5·max(0.5−|g|,0)²` 时 exposure-final **+13%**，换成逐点相等的铰链写法后持平；高光段四个铰链逐个写 +3–5%，向量化成一次 vec4 后持平（`handoff/TM01-fxc.mjs`）。
- 帧时间没测：曝光合成 0.023 ms 的全屏 pass 上每像素多两次 log2、一次 exp2 和几条 vec4 ALU，按 SOP「改了逐像素开销明显的路径才测」不测。
