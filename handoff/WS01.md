## 做了什么

| 旗云（新） | — | 塔身 9.5–12.5 km 挂一圈顺风拖长 20–30 km 的云（和我们差不多高，塔从云里穿出去） |

| 稳定缆 | 从最低两个中继站拉到 18–52 km | 从**塔顶**拉到 45–70 km 外海上的六根细线（夜里是塔两侧淡淡的「帐篷」） |

## 性能

- GPU（`dev-browser gpu-ab`，同页 ABBA 10 轮 × 20 帧，`--time frame`，1600×1200，RTX 5090 d3d11，天梯开 / 关 / 关 A/A）：正午 ×1.005 [0.984, 1.024]、夜仰看 ×1.020 [1.000, 1.106]，**都在离散度内**（中位差 ≤ 0.03 ms），远低于 +0.4 ms 上限。并行开发负载下测的，波次收尾安静窗口再复测。
- **冷编译（超门槛，报协调者）**：OW 变体（`outside-extras`）离线 FXC 对 master 交替 4 轮：**+22%（最小值）/ +14%（中位）**，门槛 +10%。已经砍过的见 README 坑点（第一版 +34%）；同轮消融里剩下没有单独的大头（环站 ≈ 6%、旗云 ≈ 5%、竖肋 / 纹理几个百分点）。OW 在首帧后后台预编，不在冷启动关键路径上。再压的方向：①旗云改成更便宜的一层（或挪进云间层）；②环站的舱段接缝 / 节点舱二选一；③天梯和建木拆成两个 W 变体（要动 `wantedOutsideKey`，归属外）。负载下 FXC 噪声 ±30%，建议安静窗口复测后再定砍不砍。
- `check:glsl`、`typecheck`、`build` 过，`dist/assets` 无 0 字节文件；截图期间控制台 0 error；非奇观场景：默认窗外程序预处理后与 master 逐字相同，`clouds.ts` 的改动只在 `uWonderOn` 时生效 → 逐位 0。

python ../../tmp/ws01/metrics.py tmp/screenshot/WS01/pairs ws-tether-noon …
# 塔身灯格 关 / 开
node scripts/dev-browser.mjs shots --port 5266 --query towerwin --only ws-tether-night --pair "" --pair "v.wonders.tetherWindows = true; v.wonders.uniforms.uWonderSky.value.w = 1;"
