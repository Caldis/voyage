## 根因（有证据）

1. 复现：太阳 −10°（左座）、−15° / −18°（右座，朝西）时，拉伸后能看到一格一格的阶梯。台阶像素指标（竖直方向「平台 + 跳变」像素占比）改前分别是 1.43% / 2.63% / 2.11%，平滑渐变约 0.01–0.1%。
2. 逐张 LUT 切到 32 位浮点（临时 URL 开关，现已删）：
   - 全部切：阶梯消失（2.63% → 0.11%）；
   - 只切天空视图 LUT：消失（0.10%）；
   - 只切空气透视 LUT、只切多次散射 LUT：没有变化（2.60% / 2.59%）。
3. 读回天空视图 LUT（32 位，绿通道，天空半边），数值分布如下（`handoff/T36-lutstats.mjs`；它依赖的临时钩子已删，复现时要按脚本头注释加回）：

| 太阳高度 | 中位数 | 90% 分位 | 最大值 | 低于 6.1e-5 的比例 |
| --- | --- | --- | --- | --- |
| 1.7° | 3.8e-3 | 2.8e-2 | 7.9e-2 | 0% |
| −6.1° | 1.2e-5 | 3.1e-4 | 1.8e-3 | 75% |
| −10° | 4.4e-8 | 1.0e-5 | 1.5e-4 | 97% |
| −14.9° | 5.7e-10 | 1.8e-8 | 3.4e-6 | 100% |
| −17.9° | 5.5e-11 | 1.5e-9 | 1.7e-7 | 100% |

LUT 的单位是「光源照度 = 1」，深暮光时的数值远低于半精度的最小次正规数 5.96e-8。每个 texel 只剩 0 / 1 / 2 个最低位，双线性插值后被自动曝光放大成和 texel 网格对齐的块。所以不是参数化稀疏，也不是后期抖动不够（抖动发生在量化之后，救不了 LUT 里已经丢掉的信息）。

## 改法

| 文件 | 内容 |
| --- | --- |
| `src/atmosphere/luts.ts` | 构造函数里检测 `OES_texture_float_linear` 和 `EXT_color_buffer_float`，两者都有就把 7 张 LUT（透射率、多次散射、辐照度、天空视图 ×2、空气透视 ×2）的 `texture.type` 改成 `FloatType`（three 在第一次 `setRenderTarget` 时才分配显存，首次渲染前改就行）。新增 `Atmosphere.float32`；URL 参数 `?lut16` 强制用半精度 |
| `src/render/pass.ts` | `renderer` 从 private 改成 public readonly（luts.ts 要用它检测扩展） |
| `README.md` | 坑点一条，调试一节加 `?lut16` |

只有天空视图 LUT 是必须改的。其余 LUT 也一起改，是因为它们同样以「照度 = 1」为单位：空气透视会用在暮光里的云和地面上，辐照度会用在环境光上，数值也会掉到下溢区，而改成 32 位的代价在噪声以内。着色器源码没有变化。T18 的霾仍在 LUT 里，这次只改了存储精度，霾的结果不变。

## 验收数据（d3d11，RTX 5090）

- 四个太阳高度、左右座：`tmp/screenshot/t36-5236/fix-sun{-6,-10,-15,-18}-{left,right}.png`，拼图 `stretch-fix.png`；改前是 `base-*` 和 `stretch-base.png`（vulkan），1:1 对照图 `crop-15-right-base-vs-fix.png`。台阶像素占比都在 0.002–0.11%，和平滑渐变持平。拉伸 ×3 后也看不出阶梯。
- 回归场景（改前 = `?lut16`，改后 = 默认）的平均差：sunset-wing 0.49/255，dusk-earthshadow 0.27，night-city 2.60。同一配置拍两次的噪声底（`noise/`）是 night-city 4.23、sunset-wing 0.87，所以改动在噪声以内。差异只出现在机翼 / 窗框边缘的抖动和城市灯点的闪烁上（`reg-diff.png`）。
- 性能（`T36-bench.mjs`，6 轮 × 30 帧中位数，半精度对 32 位）：noon-cumulus 2.58 / 2.50 ms，sunset-wing 2.58 / 2.64，dusk-earthshadow 1.88 / 1.84，night-city 5.42 / 5.62，twilight-15 2.43 / 2.50。变化在 −3.4% 到 +3.8% 之间，正负都有，属于噪声。
- 冷启动（`dev-browser.mjs cold`，d3d11）：共 15.0 s，其中大气 LUT 575 ms，后台编译 11.7 s。着色器源码没变，程序数都是 1。
- `check:glsl` 通过，`typecheck` 和 `build` 都通过，截图过程中控制台没有 error。

## 坑

- `scripts/lint-shaders.mjs` 在 Node（vite SSR）里构造 `Atmosphere` 时，传入的是只有 `render()` 的假 pass，而且没有 `location`。第一次改完 check:glsl 直接崩了（`Cannot read properties of undefined (reading 'extensions')`）。现在 luts.ts 对这两种情况都做了容忍。以后往 Atmosphere 等类的构造函数里加浏览器依赖时要记得这一点。
- 舱灯开着时，T24 的舱内倒影会盖住深暮光的天空，所以截图脚本默认把舱灯设成 `"off"`（`--cabin on` 可以恢复）。
- 用 Python 的 `open(..., 'w')` 改源码会写出 CRLF（git 会提示）。改源码用 Edit 工具，或者写文件时指定 `newline="\n"`。
