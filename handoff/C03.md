## 诊断（d3d11，1600×1200，同页冻结、64 帧真平均）

1. **远处云带的水平横纹不是步长 / 网格的问题，是受光步进挑细节格点的随机数和采样深度相关**。
   - 光照拉平（S 取常数）横纹消失、受光 od 置 0 也消失 → 横纹在光照里，不在不透明度里。
   - 步长 ×1/4（mip 不变）横纹消失；mip 降 2 级不消失；步数上限 192 → 384 逐位不变（没有用完步数）；
     进云锚定（割线 / 二分定位表面后从表面重走）反而更明显。
   - 根因：`gDetailRnd = fract(jitter + i·φ)`，和采样点在区间里的位置 `t + stepLen·jitter` 用的是同一个 jitter。
     时间累积平均的是 E_j[S(深度(j), 格点(j + iφ))]，它随「在第几步进云」（整数 i）跳变；i 逐行变，就是一条条横纹。
   - 修法（零开销）：`gDetailRnd = fract(jitter * 13.0 + float(i) * 0.6180339)`，与采样深度去相关。backlit-cu 横纹消失
     （`diag9/bl.png`）；另一种去相关（换一套 IGN）也消失，但 64 帧平均里留颗粒。`gDetailRnd = 0.5` 也消失，但会露 T32 的六边形格子边。
2. **轮廓软（边宽）来自空白处的采样间距**：掠射的薄弦长度 c < 空白步长 2dt 时，命中概率只有 c / 2dt，命中后又按整步饱和，
   不透明度随弦长线性爬升（而不是在几十米内饱和）。
   - 雷暴式「进云退回 + 8 小步」（`refine8`）只修进云那一段的积分，**提不高命中概率**：边宽不变，
     云步进 noon +140%、variety +175%，还把 noon 云芯对比 int_rng 0.22 → 0.14。不采用。
   - 有效的是「靠近表面时空白步长变细」：`layerDensity` 顺手给出 `gLayerNear = 形状包络 / 侵蚀阈值`（< 1 是被细节侵蚀掉的空白，
     越接近 1 越靠近表面），下一步空白步长按它从 2dt 渐变到更细。
   - 纯按距离全局加密不划算：`half`（步长减半）+71%，`noE2`（空白不走 2 倍）+60%。
