## 返工（2026-09-28，现行）

**做法改成「闪光按已知事件处理」**（`exposure.ts` LOCAL_FRAG + main.ts 一行接线）：
- main.ts 在 `exposure.render` 前一行：`exposure.flash = Math.max(u.uStrobe.value, THREE.MathUtils.smoothstep(cloudUniforms.uFlash.value.w, 0.3, 3));`（频闪开关、闪电亮度）。不接线时 flash 恒 0，逐位退回 T48b。
- 粗网格（屏幕 1/16，RG ping-pong）：R = 状态（线性亮度），G = 扣除量。不闪时 k = 1（状态每帧等于当帧）、扣除量 0；闪时状态按 τ 0.3 s 跟（0.25 → 0.3：S-50 变暗像素 210 → 110，`rw-tau/`），扣除量 = 当帧粗格 − **更新前**的状态（线性，第一帧整份，与帧率无关，P3-2）。
- 最终合成：`lb` 用 `max(Lfine − T, Lfine/16)`（不闪时按 T48b 原式，逐位相同）；再让闪光在像素里那一份（`uGlare·T / Y(c)`）不吃局部适应——
  否则「按闪光前的状态适应」本身就不单调：常亮位置灯把周围压着，叠上来的闪光在灯旁一起被压，r 15 → 55 反而上升 15–25 级（线性域扣也一样，实测）。
- P3：NaN / Inf / 负的状态按「直接收敛」重来（P3-3）；半精度停滞不再有影响（不闪时 k = 1，闪的时候只有几十毫秒，P3-1）；`T48b-ab.mjs` 每个变体开头复原频闪与 localDt（P3-4）。

## 改了什么

`src/render/exposure.ts`（main.ts **零接线**）：

1. **（已推翻，见「返工」）瞬态扣除（时间常数）**：新增 `LOCAL_FRAG` / `Exposure.localMat`（程序名 `exposure-local`）。
   粗网格 = 眩光纹理的 1/8（屏幕 1/16，1600×1200 下 100×75），每个纹素 16 次双线性取样 = 8×8 眩光纹素的平均亮度，
   对数域指数平滑（变亮 τ 0.25 s、变暗 τ 0.1 s），RG ping-pong：R = 平滑后的 log2 亮度（状态），G = max(当帧 − 平滑 − 死区, 0)。
   最终合成的局部适应照旧用**当帧**眩光低通（与 T48b 同），只把 `lb` 再减去 `texture(uLocalLum, vUv).g`：大片、突然的变亮（频闪、闪电）不进适应。
   - 冻结（dt = 0）与 `snap()` 视为直接收敛（G = 0）：**冻结时非机翼像素与 T48b 逐位相同**，所有冻结对照工具照旧可用。
   - 目标在第一次 `render` 时按 `bloom.image` 尺寸 / `bloom.type` 建，尺寸变了自动重建。
   - 调试句柄 `exposure.localDt`：`null` = 真实 dt；`0` = 保持（冻结后钉亮频闪 / 按住闪电，模拟「瞬态还没进适应」）；
     设 0.05 后 `v.benchFrame(1)` = 让 50 ms 进适应。`localMat.uniforms.uLocalRate = (变亮 1/s, 变暗 1/s, 死区档)`，默认 (4, 10, 0)。
   - **第一版被推翻**：先做的是整张半分辨率低通的指数平滑（最省、稳态与 T48b 逐点相同）。瞬态挡住了，但运动中「去趋势后整片亮度抖动」
     比即时适应高约 1.6 倍（motion3 / motion5，配对中位 0.62–0.66 的倒数）：每个移动的灯点跨过低通纹素都要「先亮、再被压」。
     改成只对粗网格求瞬态，移动的灯点仍即时适应。
2. **机翼**：门控用 TM02 已算好的 `notWing`（dW 判据，零额外采样）。
   `x *= mix(1 + max(glareFrac, uNightLocal.z)·(gLoc − 1), gLoc, notWing)`；`glareFrac` = 像素里眩光（`uGlare·glare`）占的亮度比例；
   `uNightLocal` vec2 → vec3，z = 0.85。非机翼像素 notWing = 1，与 T48b 逐点相同。
   - **为什么不是简报说的「门控直接乘非机翼」**：试过（r1），1 km 低空贴着白灯的翼面出现 **1256 px 死白块**，灯的眩光在翼面一侧比天空一侧大一圈（剪影处光晕断开）。
     只压眩光（z = 0）后光晕两侧一样大，但死白块仍约 670 px。z 扫描见下表，取 0.85。
3. `handoff/T48b-ab.mjs`（P2-2）：每个场景冻结、等瓦片后先拍预热图，直到连续两张 PNG 逐字节相同（最多 6 张；实测 2–4 张稳定）；收尾复原 `exposure.localDt`。
4. `scripts/lint-shaders.mjs` 登记 `exposure-local`，`scripts/passes.mjs` 给它起名「局部适应低通」（各一行）。
5. 新脚本 `handoff/T48c-motion.mjs`：不冻结、飞机照常飞，按模式（tau / inst / noLocal / tauF / tauS / dz05…）轮流测；
   `--inpage` 在页内每个 rAF 紧跟主循环 readPixels 裁剪区（**截图会让帧间隔忽长忽短，带时间常数的一方被额外调制，别用截图测**），
   每轮模式顺序轮换，写 `inpage.json`；分析 `handoff/T48c-cfg/t48c_inpage.py`（配对比值 + 去趋势抖动）。
