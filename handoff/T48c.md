## 改了什么（`src/render/exposure.ts`，main.ts 零接线）

1. **低通带时间常数**：新增 `LOCAL_FRAG` + `Exposure.localMat`，一个半分辨率（与眩光纹理同尺寸、同类型，R 单通道）ping-pong，
   存「眩光亮度 ÷ uBloomLevels」（线性），在对数域做指数平滑：变亮 τ 0.25 s、变暗 τ 0.1 s（`uLocalRate = (4, 10)`）。
   最终合成的 `lb` 改读 `uLocalLum`（新 sampler，曝光合成 5 → 6 个）。
   - 为什么这样最省：眩光纹理本来就是半分辨率、本来就要算；多一个 ~50 万像素、2 次取样的小 pass，没有新 mip 链。
     存线性亮度而不是 log：稳态（prev = cur）时最终合成双线性取样的结果与 T48b「对眩光纹理取样再求亮度」逐点相同。
   - 纹理在第一次 `render` 时按 `bloom.image` 的尺寸 / `bloom.type` 建，尺寸变了自动重建，所以 main.ts 不用接线。
   - **冻结（dt = 0）视为直接收敛**（静止画面的稳态就是当帧）：所有冻结对照工具照旧逐像素可比，frozen 下 final 与 T48b 同。
     `exposure.snap()` 同时重置它。
   - 调试句柄 `exposure.localDt`：`null` = 真实 dt；`0` = 保持不动（冻结后钉亮频闪 / 按住闪电，模拟「瞬态还没进适应」）；
     设 0.05 再 `benchFrame(1)` = 模拟 50 ms 的频闪进了多少适应。
2. **机翼上只压眩光 + 翼面自身 0.7**：门控用 TM02 已算好的 `notWing`（dW 判据，不加采样）。
   `x *= mix(1 + max(glareFrac, uNightLocal.z)·(gLoc − 1), gLoc, notWing)`，`glareFrac` = 这个像素里眩光（`uGlare·glare`）占的亮度比例，
   `uNightLocal` 从 vec2 改 vec3，z = 0.7。非机翼像素 notWing = 1，与 T48b 逐点相同。
   - 为什么不是简报说的「门控直接乘非机翼」：试过（z 等效 0 且眩光也不压），1 km 低空贴着白灯的翼面出现 **1256 px 的死白块**，
     灯的眩光在翼面一侧比天空一侧大一圈（剪影处光晕断开）。只压眩光后光晕两侧一样大；翼面自身的比例 z 扫描见下表。
3. `handoff/T48b-ab.mjs`：每个场景冻结、等瓦片后先拍预热图，直到连续两张 PNG 逐字节相同（最多 6 张）；收尾复原 `exposure.localDt`。
4. `scripts/lint-shaders.mjs` 登记 `exposure-local`；`scripts/passes.mjs` 给它起名「局部适应低通」（各一行）。
5. 新脚本 `handoff/T48c-motion.mjs`：不冻结、飞机照常飞，按模式（tau / inst / noLocal / tauF / tau15）轮流截同一裁剪。
