## 做了什么

| 文件 | 内容 |

| `scripts/weather-stats.mts` | 新增 `wind` 统计段（默认开启，`--only wind` 单跑）和 32 条风场断言；改前的 `weather.ts` 没有 `wind()` 时记一条失败，不崩溃 |
| `README.md` | 天气坑点加一条：风场的调用频率、逐帧积分、方向只在硬切时换、惰性 getter、连续性门限 |

## 风场的构成（数据表与出处）

依据标注同 `research/WX11-DESIGN.md`：[文献] 有链接；[教科书] Stull 1988 / Holton / Wallace & Hobbs，按记忆转述；[估算] 推算或经验值。

**250 hPa（≈ 10.5 km，数值按急流层 200–250 hPa 取）**

| 成分 | 取值 | 依据 |
| --- | --- | --- |
| 急流轴纬度（按月，1–12） | 32, 32, 32.5, 33, 35, 38, 41, 42, 40, 36, 33, 32 °N | 1 月 32°N、4 月与 1 月相近、7 月 ≥ 40°N：[文献 Zhang et al. 2006, GRL 33, L11708]；其余月份 [估算] |
| 急流峰值（按月，扰动前） | 75, 73, 68, 57, 46, 38, 35, 33, 36, 46, 60, 72 m/s | 1 月按「月均 > 70」反推（叠扰动与槽脊后月均核心约 73）[Zhang06]；夏季 30–40 [教科书，量级]；其余 [估算] |
| 经向宽度 | 南侧 8 + 5×冬季指数（冬 13°、夏 8°），北侧 8° | 冬季副热带西风伸到 15–20°N [教科书]；宽度 [估算] |
| 纬向不均匀 | 140°E 最强，偏离 25° 以上减到约 0.62–0.77（冬季明显、夏季平） | 冬季核心在日本上空 [Zhang06]；衰减量 [估算] |
| 急流北侧背景西风 | 12–20 m/s，65–75°N 减弱 | [估算] |
| 槽脊 | 轴纬度 ±2.5°（冬）到 ±4°（夏）摆动，经度尺度 22°、东移约 8°/天、几天演变；v = u × 轴线斜率 | 槽脊东移 5–10 m/s 的量级 [估算] |
| 风速扰动 | ×(0.8–1.2)，千公里 / 40 小时尺度 | [估算] |
| 夏季热带东风 | −16 × 季节 × exp(−((lat−15)/9)²) × (120°E 以西 1 → 150°E 0.3)，6–9 月 | 核心 150 hPa、约 15°N、35–40 m/s [文献 Koteswaram 1958, Tellus 10]；250 hPa 上更弱，华南 25°N 以南 5–20 [估算] |
| 方向扰动 | ±10° | [估算] |

**850 hPa（≈ 1.5 km）**：下面各项矢量相加，再整体转 ±25°、乘 ×(0.7–1.3)（千公里 / 1–2 天尺度，WX11-DESIGN §1.2 建议值 [估算]）

| 成分 | 取值 | 依据 |
| --- | --- | --- |
| 热成风部分 | 0.15 × 250 hPa 西风，只在约 25°N 以北（22–32°N 过渡） | [估算]；冬季 850 hPa 东西风分界约 25–30°N [教科书，量级] |
| 冬季风 | 来向 = `winterMonsoonFromDeg`（128°E 以东 315°、120°E 以西 350°），22–28°N 往南转成东北风 45°；风速 4 + 8 × 寒潮脉动（软阈值） | 日本海寒潮 10–20、平时 5–8 m/s [教科书，量级] |
| 信风 | 来向 75°、6 m/s，6–33°N 的 100°E 以东，夏季季风区让位 | 18–28°N 洋面偏东—东北风 5–8 [教科书] |
| 夏季西南季风 | 来向 225°、7 m/s，锋面以南、97–132°E | 华南到长江 5–10 [教科书] |
| 副高环流 | 脊线（= 锋面带 − 8°，与 `subtropicalHigh` 同源）以南东风、以北西风，西侧偏南风，5 m/s | 副高西北侧的西南气流 [教科书]；强度 [估算] |
| 梅雨低空急流 | 来向 235°、9 m/s，锋轴以南 2.5°（宽 1.6°），和锋面云系同一个抽签但门槛放软 | 梅雨期 850 hPa 常有 ≥ 12 m/s [教科书] |

**500 hPa（≈ 5.5 km）**：0.45 × 250 hPa + 0.35 × 850 hPa，再转 ±15°。**与设计文档的 0.4 / 0.6 不同**：按 0.4 / 0.6 算，日本 1 月 500 hPa 约 47 m/s，超出设计表里的 25–40；0.45 / 0.35 给出日本 1 月约 36、华东 1 月约 27、华南 7 月约 2.5、梅雨锋约 16，都落在设计表的区间里 [估算]。

**地面（10 m）与边界层**

| 项 | 取值 | 依据 |
| --- | --- | --- |
| 边界层顶 | 1 km；以下风速按对数律 ∣G∣·ln(z/z₀)/ln(h/z₀)，G = 850 hPa 风 | 对数廓线 [教科书：Stull §9]；外推到边界层顶是简化 [估算]，但它给出的 10 m / G 比恰好是教科书的海上 0.6–0.8、陆上 0.3–0.5 |
| z₀ | 海面按 Charnock（α = 0.011，下限 1e-5 m），陆地 0.2 m（取 0.1 时陆上 10 m / 850 恰好 = 0.5，贴在区间边上），按陆地比例在对数上插值 | [教科书] |
| 埃克曼偏角 | 海上 15°、陆上 35°（北半球逆时针「后退」），2–8° 纬度以内压到 0；往上按 ln z 线性转回 | 海上 10–20°、陆上 25–45° [教科书] |
| 陆地比例 | `coarseLand` 在 0.5° 格点上双线性插值 | 避免地面风在海岸线上一步跳变 |

## 「故意改坏一处 → 断言失败」的证明

每次只改一处，默认种子跑 `--only wind`，改完 `git checkout` 恢复（脚本在 scratchpad：`wx11a_sabotage.py` + `wx11a-sabotage.sh`）：

| 改坏什么 | 失败的断言（值 / 门限） |
| --- | --- |
| **改前（master 的 weather.ts）** | 「WeatherField.wind() 存在」失败（其余风场断言无从计算） |
| 去掉夏季热带东风 | 华南 7 月 250 hPa 纬向风 0.3（< 0） |
| 急流全年停在 32°N（不随季节北移） | 7 月急流轴 33.0°N（≥ 38） |
| 埃克曼偏角反号（地面风顺时针偏） | 海上 −15°（10–20）、陆上 −35°（25–45） |
| **雷暴漂移改回改前的写死常数**（25°N 以北往东、以南往西） | 夹角 p90 69.5°（≤ 50）、25°N 以南 p90 168.2°（≤ 90）、速度相关 0.50（≥ 0.7） |
| 冬季风来向反了（东南风） | 日本海来向 0.2%（≥ 70）、风速中位 7.6（8–18）、信风带 1 月东风 68.2%（≥ 70） |
| 850 hPa 扰动时间尺度 30 h → 2 h | 连续性 1 h p99：850 58.6%、500 29.5%、地面 53.7%（≤ 15） |
| 陆地粗糙度按海面取 | 陆上 10 m 风速占 850 hPa 73.6%（30–50） |

**一个教训（按 WX10 审查的要求当场发现的）**：设计验收里的「雷暴漂移与 500 hPa 风向夹角中位 ≤ 30°」**改前的写死常数也能过**（16.3°）——写死的方向本来就是气候平均方向，只在尾巴上错。所以另加了三条尾巴 / 相关性断言，改前全部失败。这条中位数保留（设计验收），但它本身没有区分力。

## 接口（给 WX11b / WX11c）

```ts
import { WeatherField, windAt, windShear, steeringWind, blMeanWind, windToLocal, windFromDeg, windSpeed, WIND_LEVEL_KM } from "./weather";

const prof = field.wind(lat, lon, simTime);     // 约 4 µs；或者读 sample.wind（惰性，同一份）
windAt(prof, 11.0)      // 某高度的风 {u 东, v 北} m/s；约 0.04 µs，可以每帧调
windToLocal(w)          // → {x, z}（场景 x 东、z 南）= (u, −v)，写 uniform 前用它换坐标
windFromDeg(w)          // 气象来向（0 北风、270 西风），给调试面板 / 日志
steeringWind(prof)      // 700–500 hPa 平均：雷暴漂移（WX11c 的 uStormAdvect）
blMeanWind(prof)        // 0–1.5 km 平均：云街 / 卷轴方向（WX11b 的 uLowWind、WX11e）
windShear(prof, z1, z2) // 切变：卷云钩 / 积云倾斜（WX11d）
```

- **WX11b（方向）**：`uUpperWind` ← `windToLocal(prof.p250)` 归一化、量化到 5°；`uHighWind` ← 卷云层高度 `windAt(prof, 11.5–12.5)` 的方向；`uLowWind` ← `blMeanWind(prof)` 的方向。**只在硬切（借遮挡 / 摆放雷暴台风）那一刻取**，平时不写（设计坑 A / B）。硬切本来就在 `WeatherDirector` 的 300 模拟秒取样点上，`sample.wind` 顺手就有。
- **WX11c（平流）**：层状云的平流速度取 `windAt(prof, (bottom + top) / 2)`，prof 用导演最近一次取样的结果（300 模拟秒一次），在两次取样之间对速度做一阶低通（约 30 模拟秒），**位移逐帧积分**（`+= v × simDt`），不要写成 `t × v`。平流是整层刚体平移，不要逐像素取风。
- 雷暴系统在天气场里已经按引导气流漂移（`StormSystemSample.drift`，km/h）；WX11c 给场景里已摆放的单体加漂移时，读同一个值即可和天气场一致。
- 单位：风一律 m/s，`drift` 是 km/h（和 `stormsNear` 原来的 ve / vn 一致）。
- WX23（Open-Meteo 实测）要替换时，只需让 `wind()` 返回实测的 850 / 500 / 250 hPa，`sfc` 可以继续用这里的对数律 + 埃克曼从 850 推。

## 运行时开销与调用频率

临时微基准（Node，两轮，和门禁并行跑、有噪声；新旧 `weather.ts` 同进程对照，脚本放在 `tmp/wx11a-base/`，交付前已删）：

| 调用 | master | WX11a |
| --- | --- | --- |
| `sample()` 沿航线（不读 wind） | 8.6–10.9 µs | 9.7–11.7 µs（多一个闭包，约 +1 µs） |
| `sample().wind`（读惰性字段） | — | 13.8–14.6 µs |
| `wind()` | — | 3.6–3.9 µs |
| `windAt(profile, 高度)` | — | 0.04 µs |
| `blMeanWind(profile)` | — | 0.45 µs |
| `stormsNear(…, 340 km)` | 1.03 ms | 1.05–1.09 ms（搜索半径 +250 → +330 km，每个出生的系统多算一次 `wind()`） |

调用频率：**本任务没有任何每帧调用**。`sample()` 由导演每 300 模拟秒调一次（60× 下约 5 真实秒一次），小地图（调试用，默认关）每 800 ms 取 48×48 个点但不读 `wind`，惰性 getter 让它不付风场的钱。`stormsNear` 同样按 300 模拟秒节奏。WX11b / c 接进来后，每帧只该有 `windAt(缓存的 profile, 高度)` 这种纯算术。

## 踩到的坑

- **设计验收的「漂移夹角中位 ≤ 30°」没有区分力**：见上一节。以后给「方向跟风走」写断言，除了中位数还要看尾巴（p90）或相关系数，写死的气候平均方向只在尾巴上露馅。
- **门限不要贴在物理常数恰好给出的值上**：陆地 z₀ 取 0.1 m 时，对数律给出的 10 m / 850 hPa 风速比是 ln(10/0.1) / ln(1000/0.1) = 0.5000，正好压在教科书区间 0.3–0.5 的上沿，6 个种子都是 50.0，浮点稍一偏就翻。改成 0.2 m（46%）。识别：某条断言在所有种子上值完全相同且等于门限。
- **「故意改坏」实验用 `git checkout -- 文件` 恢复，会连带冲掉没提交的正经修改**：这次就把刚改的 z₀ 冲掉了一次（事后发现、重改）。先提交检查点，再做破坏实验。

## 没做 / 留给后续

- 导演、小地图、uniform 都没接风（WX11b / WX11c / WX11g）。小地图的风向箭头（可选）没做。
- 台风周围的风场（气旋式入流 / 反气旋出流）没做：设计文档明确不在 C-TYPH 之前碰台风。台风附近的风仍是气候态。
- 南半球 / 赤道以南只做了最简单的处理（急流压掉、埃克曼反号并在赤道附近压到 0），东亚航线用不到。
- 夏季急流核心的经度（可能西移到青藏高原上空）没有核对文献，只把夏季的纬向不均匀压平了 [估算]。
- 850 hPa 在日本本州 7 月主要是偏西风（约 5 m/s），设计表写的是「偏南—西南 5–10」[估算]，没有断言约束；如果美术上需要，可在副高西北侧的偏南风里加大经度范围。
