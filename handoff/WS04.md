## 做了什么（只改 `src/wonders/floatcity.glsl.ts` 与 `catalog.ts` 的浮空城条目）

| 部件 | 小岛版（W03，保留） | 巨构版（主） | 手法（WONDER_SCALE §1） |
| --- | --- | --- | --- |
| 尺寸 | 直径约 6 km，台地底 7.5 km，冠顶约 11.7 km | 按种子：直径 25–35 km（水平 ×4.2–5.8），台地底 12–16 km，冠顶 25–32 km | 比雷暴云还大；冠顶高过视平线 11–13°，要仰视树冠底面 |
| 放大方法 | — | 「模型坐标」：水平 ÷Kh、台地以上 ÷0.82Kh、以下 ÷0.75Kh（分段线性连续），SDF 在模型坐标求值 × min(K) | 造型一次到位，细节跟着放大成第二级 |
| 岩座 / 根 | 7 条粗根垂到 3.3 km | 岩锥尖不低于 2.2 km；7 条粗根里约三分之二一直垂进云海（根尖海拔 1.4–3 km），其余断在 4.5–8.5 km；根更细、摆动更大 | 贯穿云海（M5）；根尖在云顶搅起云涡（新介质，顺风拖长、受云影） |
| 瀑布 | 1–2 道，落差约 3.6 km | 3–5 道，整道 ×2.8：出水口约 0.3 km 宽、落差约 10 km，蒸发更慢、化雾的部分减半 | 十公里的水柱当尺度参照，一路化雾 |
| 台地 / 残塔细节 | 两级（轮廓、台阶 + 拱廊） | 三级：轮廓（约 350 px）→ 4 层台阶、拱廊（真实约 450 m 一跨，约 5 px）、残塔 → 墙面小窗 / 石砌层（约 100 m，足迹超过四分之一周期就平均）+ 雨痕 / 苔斑 + 垂下的藤蔓带 | 远处平均，不闪（见闪烁一节） |
| 树冠 | 团块 + 两级 Worley | 再加一级小团块（约 1.2 km 一丛，受光起伏）+ 林冠纹理（约 250 m，按足迹选 mip） | |
| 大气分层 | 按距离往天空色靠 | 再按海拔分层：8 km 以下更朦胧、22 km 以上几乎不加 | 下段蓝灰、上段清楚 |
| 雾 | 整个雾罩一层薄雾 + 叶雾 | 去掉（40 km 的雾罩逆光时是光晕、把城蒙灰；叶雾放大后成「霉斑」），空气交给大气本身 | |
| 尺度参照（新） | — | 一架和我们同高度（10.9–11.7 km）的航班拖着航迹云从城边擦过（离城轴 1.05–1.4 倍城半径），450 s 一趟；航迹云是线积分闭式解（宽度随时间变宽、足迹展宽能量守恒、一段浓一段淡） | 几十米的飞机 vs 30 km 的城 |
| 投影 | 3 km 球，浓度 0.6 | 14 × 6 × 14 km 椭球，浓度 0.75（云海上约 28 km 宽） | 影子量出尺寸 |
| 布局 | 75–130 km | 90–140 km，baseKm 14，包围盒 ±45 × [−14.5, 22] km（水平放宽是为航迹云），介质步长 0.5 km | |

## 已知问题 / 留给之后

- **M6 没达标**：目视分层已经有了，量法（和背后天空的相对对比度）在地平线附近被亮的霾带拉高；如果要继续，方向是下段再朦胧一点、或者改用「和同高度天空的色差」来量。属于细微打磨，没继续。
- **性能**：110 km 在场约 +0.9 ms，80 km 更多；冷编译 +56%（不在启动路径）。继续压的方向：巨构分支合并、根须帘子在远处换成纯纹理（不走介质）。
- 浮现时那团「云」是一个 35 km 的近乎正圆的球（`v4/ws04-rise-110.png`），和 W03 一样「形状不太对劲」，但放大后更像一颗棉花球；可以让它更扁、底部更平。
- 树冠受光的团块在黄昏里偏灰白（顺光 + 空气透视），远看有点像地衣斑。
- 航迹云只有在飞机经过的那几分钟里有（450 s 一趟、约 4 分钟可见）；截图机位里它不一定在。`ws04-contrail-*` 场景用 `v.wonders.clock = …` 把时间拨到飞机正在城边。
- 投影在这几个机位看不到（太阳在前 / 后方）；没有做侧光机位的截图。
- 回归场景 `wonder-floatcity-day / -dusk`（80 km）画面会整体变化：城占了窗的一半，可以考虑把回归机位改到 110 km（`scripts/scenarios.mjs` 不在归属里，留给协调者）。

## 怎么复现

```bash
cd apps/voyage && npx vite --port 5280 --strictPort --host 127.0.0.1
node apps/voyage/scripts/dev-browser.mjs shots --port 5280 --query 'voyage=0' --scenes-file apps/voyage/handoff/WS04-scenes.json --out tmp/screenshot/WS04/x
# 表面掩码：--cloud-live --pair '…surface = true; v.wonders.uniforms.uWonderUse.value.x = 1; …' --pair '…= false; …value.x = 0; …'
python apps/voyage/handoff/WS04-metrics.py <a.png> <b.png> 580 4 600
python apps/voyage/handoff/WS04-mkab.py   # 生成 tmp/ws04-gpu.json、tmp/ws04-live.json
node apps/voyage/scripts/dev-browser.mjs gpu-ab --port 5280 --query 'voyage=0' --jobs tmp/ws04-gpu.json --time clouds --rounds 8
node apps/voyage/scripts/dev-browser.mjs ab --port 5280 --query 'voyage=0' --jobs tmp/ws04-live.json
cd apps/voyage && node scripts/shader-budget.mjs --baseline <master 的 apps/voyage 绝对路径> --only wonder-layer --rounds 3
```
控制台：`__voyage.wonders.enabled = true; __voyage.wonders.trigger("floatcity", { forwardOffsetDeg: 0, distKm: 110, reveal: 1, seed: 0.23 })`（小岛版 id `floatcity-small`）。
